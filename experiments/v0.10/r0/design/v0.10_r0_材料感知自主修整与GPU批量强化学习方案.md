# v0.10 r0：材料感知的自主修整与GPU批量强化学习实验方案

日期：2026-09-25。状态：供审查的设计稿，未实现、未启动新训练。证据范围：L1仿真。

本方案面向项目开发者、实验复现者及组会审查。数值预算和门槛是拟定工程标准，不是已实现成绩、厂家参数或行业标准。审查后先完成开发集试验，再冻结正式配置；冻结后不得根据最终测试降低标准。后续修订另建r1，不覆盖本稿。

## 1. 本轮要回答的问题

目标不是让机械臂执行更多动作，而是让它根据墙面缺陷和工具余料，决定是否补料、补多少，以及如何用合适的接触路径提高施工质量。在已有合格底层、只剩边缘凸起时，应能尝试不添加新料的修整；在裸墙或明显薄区时，应能主动补料。

同时，将训练用材料代理环境改成可批量执行的GPU后端，提高单位时间的有效试错量。算法有效性与GPU加速分成两条证据链，不能用“训练更久”冒充算法更优，也不能用“GPU利用率更高”冒充端到端更快。

本轮不引入外部大模型API、VLA或真实D435视觉网络，不进行实体运动。它首先解决当前自主修整链路的基本可靠性，后续才适合接入更复杂的视觉与任务决策模型。

## 3. 总体组织：三条工作线、逐级放行

A线：验证材料与运动能力。先证明任务在当前模型中可解决，尤其是空刀修棱、连续长刀及已合格区域保护。

B线：改善策略。独立装料决策、余料状态、易探索的路径表达、有限示教和结果驱动的强化学习。

C线：提高采样效率。CPU参考实现、GPU等价实现、批量采样、异步记录与详细性能剖析。

依赖顺序：A的受控案例通过 → B的小规模行为验证；C先对冻结的旧CPU物理进行等价迁移 → 再支持B正式训练。若A发现物理缺陷，应另立物理版本并在两个后端同步修正，再重新冻结；不得只改GPU版的“效果”。

## 4. 任务与状态定义

### 4.1 区域和材料账本

沿用目标20×20 cm、四周3 cm操作缓冲、完整50×50 cm材料网格；网格5 mm。目标厚度2 mm，合格1.5–2.5 mm。外框不是需要涂满的区域。

缓冲允许工具经过和材料暂存，但不意味着可任意堆料。分别记录目标区质量、缓冲区材料体积/最大厚度、外部流失。正式比较不缩小目标区、不把失败边缘裁掉。

总材料账本：初始墙面 + 初始工具 + 从料源实际取出 = 当前墙面 + 当前工具 + 回收容器 + 掉落/域外损失。各项区分净值和累计值，不能用重置工具数组让材料消失。墙面刮回材料不是新增材料。

### 4.2 八类场景

1. 裸墙；2. 局部缺料；3. 已涂粗糙层；4. 单侧边缘凸棱；5. 角落堆积；6. 邻接高低区域；7. 接近合格但有小缺陷；8. 完全合格的保持场景。

每类随机化缺陷位置、幅度、宽度、方向及工具初始负载；包含0、少量及较多余料。保持场景用于检验“不破坏”和合理停止，不计入必须施工的完成率分母；同时报告包含所有场景的总体值。

初始工具负载是一种场景条件，不是假装所有修整都可免费得到干净工具。初始状态记录来源；所有比较使用同一场景包。

### 4.3 策略能看到什么

主策略输入：带噪声厚度图、有效性/置信图、由这些观测计算的局部高低差与边缘特征、工具负载估计及不确定度、上次动作与执行结果、已用材料和时间、当前接触状态。目标/缓冲掩码是公开任务条件。

不直接给主策略无噪声墙面、真实缺陷标签或精确余料。奖励与审计可读真值。v0.10仍是传感器代理，不声称已经用真实RGB-D识别厚度或已安装力传感器。

工具观测增加“检查工具”传感器代理：对工具材料图测量加入噪声、遮挡和偏置，估计总量、分布和不确定度。估计器通过装料记录、上一次估计及检查结果更新；不得暗中读取仿真精确吸附/沉积通量作为实机可获得输入。真值余料只放诊断组。

首版噪声扫描：总体体积误差相对5%/15%/30%加绝对0.5 mL底噪，遮挡0/20/40%，固定偏置与逐帧噪声分别建模。这些是假设，需未来测量；主组采用何种组合在开发集冻结，并报告去掉工具检查时的退化。

## 5. 先验证可做，再训练模型

### P0-A：空刀、带料与刀路的受控对照

固定一批开发场景：边缘凸棱和局部高点各24个，共48个；另有12个裸墙补料正例。每次分支从完全相同墙面、工具、材料参数、随机数状态开始，不是上一刀之后顺序接着试。

边缘/高点条件：新增料0/6/12/18 mL × 路径长度6/12/20 cm。优先沿凸棱方向，工具角度/压力/速度先固定可执行组合。先名义材料环境筛查，再把短、中、长各至少10条代表路径放完整MuJoCo执行。不可达组合保留为失败，不静默缩短。

记录：高点超量减少、原合格区域损坏、新薄区、新堆积、实际接触长度、峰值力/跟踪误差、时间、新料量及材料守恒。

判断：若空刀的可执行轨迹也不能降低缺陷，暂停大规模RL；排查材料转移、刀口间隙、倾角和执行误差。若长轨迹不优于短轨迹，不把“越长越好”写入奖励，转为研究最佳长度的条件。初始最低能力门槛：至少80%的受控边缘案例存在一条可执行动作使超量体积下降20%以上，且合格区域损坏不超过2个百分点；不足需记录任务可解性问题。

### P0-B：装料与动作的因果诊断

对固定状态s和固定路径a，比较实际不补料与补不同量后的质量、损失、时间。记 C(s,a,q)=结果J(q)-结果J(0)，正值表示该固定刀路下装料更差。

这是局部反事实，不等于全局最优：料量变化后最佳刀路也可能变化。补充小范围路径×料量联合扫描，区分“料不该加”和“料量与刀路不匹配”。

反事实分支先用于诊断和开发，不混入主PPO的on-policy batch。若后续训练补料价值辅助头，应列为独立方法组，计入额外仿真预算，且不得使用最终测试分支训练。

## 6. 策略结构与动作接口

### 6.1 可训练与固定的部分

主方案使用可训练空间编码器、状态融合网络和两个条件动作头：操作头决定装料/接触/检查/结束；连续参数头按所选操作输出参数。两个头共享特征并通过PPO联合训练。它们是功能分工，不是调用外部语言模型。

建议编码器：6通道100×100输入（厚度/置信/有效性/两方向梯度/目标掩码），3层卷积32/64/64通道、3×3卷积、步长2，保留为5×5空间特征再投影256维；工具状态与历史标量经MLP到64维，融合为256维。必须记录空间坐标，避免完全全局池化丢失“凸起在左还是右”。

操作头与连续参数头输出策略分布，critic输出状态价值。先无循环记忆，由显式余料估计器与历史状态承担记忆；GRU不同时加入，避免变量太多。旧MLP是容量/结构对照，不能把CNN优势直接解释成动作设计优势。

固定部分：材料模型、传感器代理、动作解码、几何可达性及运动控制器；IK不通过PPO训练。低层执行器不是已训练VLA。完整MuJoCo提供执行验收。

### 6.2 主组操作

- LOAD(q)：主动去料源，q在0–24 mL内，0视为不取料但若执行往返仍记时间；实际转移量以料源减少计算。与CONTACT分开，不默认每刀加料。
- CONTACT：输出连续刀路、姿态、力和速度参数。材料是否沉积或刮回由状态和接触计算决定，不人为把“修平模式”设置为禁止沉积。
- INSPECT：选择墙面或工具检查，消耗明确时间，改善相应估计，不免费刷新所有观测。
- FINISH_REQUEST：可以随时请求结束。记录“达标结束”或“未达标退出”；失败不能算完成，不能强制把策略留在环境里刷动作。

装料只受工具容量、料源余量、状态可执行性限制，不用真值规则硬禁“有凸起时装料”。装料判断应由策略学会。

### 6.3 更容易探索的路径参数

将独立起终点改为：起点(u,v)、方向θ、长度L、两个中间控制点的沿向/横向偏移，共8个几何参数；加首尾刀面方向2个、倾角/法向力/速度各3个，仍19维。

候选长度范围3–26 cm；局部诊断另保留5 mm短接触，不作为主组默认。主范围需通过可达与材料采样收敛验证后冻结。允许直线、斜线、弯曲，不奖励任何特定形状。

端点和中间控制点采用有界条件采样或拒绝规则，不能事后clip后仍使用未裁剪动作的log概率。记录提议动作、执行动作和拒绝原因。工具扫掠范围可经过缓冲区，碰撞与可达约束不因追求探索放宽。

倾角0–35°、力0.5–15 N、速度0.02–0.12 m/s作为与v9一致的起点；沿用更高层硬限制。使用连续包角的方向表示并检验±π接缝。初始探索将短3–8、中8–16、长16–26 cm均覆盖；通过初始化采样分布实现，不在训练中偷偷替换策略动作。

### 6.4 长轨迹的数值分辨率

不能长短路径一律只用28个接触采样点。先进行步长2.5/1.25/0.625 mm的收敛测试，选择J变化<1%、RMSE变化<0.02 mm的最粗分辨率；同时检查姿态变化、时间积分、接触力峰值。

数值细分属于环境子步，不算多次高层动作，但需计入物理计算量。GPU版用固定上限加mask或按长度分桶，不截断长动作。正式学习组全部使用同一冻结数值设置。

### 6.5 连续接触和清刀：作为独立扩展

主组先验证长单刀。C组再开放CONTACT_NEW、CONTINUE、LIFT：CONTINUE起点等于当前实际接触点，不可跳转；给定下一段方向/长度等，保持速度、姿态与受力连续，反向移动重新计算刀口迎角。每段仍按3–26 cm，单个连续接触串总长暂定最多52 cm，单串最多4段。结束、去料源、检查工具前必须先分离。

只有机器人执行器能够从当前接触态续接且完整轨迹通过验证，才能纳入主结论；不允许名义环境连着走、MuJoCo每段偷偷撤离。评价累计实际接触距离、接触中断率和扫掠重叠率。

卸料/清刀不在本轮核心矩阵免费提供。扩展D需建模清刀位置、运输姿态、清刀耗时、残留比例和回收容器。初始空刀修整能力测试不等于部署时可凭空清刀。D不通过时保留为未实现，不能以直接清零余料代替。

## 7. 奖励：分清材料使用、浪费和动作后果

### 7.1 基础目标

保留v9固定质量指标J作为可比终态指标：厚度RMSE、合格覆盖、粗糙度、边缘RMSE和边缘超量。另报告原合格区域损坏率，不用总分掩盖局部恶化。

每个转移记录独立成本分量：实际从料源取出体积、装料次数、丢弃/掉落/域外损失、耗时、无效动作、保护区损坏。操作头和路径头都通过未来回报更新，不手工把失败50%归给料、50%归给动作。

建议开发起点：新料每18 mL成本0.2、每次实际取料成本0.05、时间每秒0.001、每18 mL不可回收损失成本1、无效动作成本2。新增保护项以“初始合格像素当前损坏比例P”的增量作形状奖励，不在每一帧重复累计同一损坏。各项原始量与加权量都保存。

新料成本扫描0/0.05/0.2/0.5每18 mL，装料次数成本0/0.05/0.2；先在受控裸墙和修棱短试中筛选不出现拒绝必要补料的组合，最多4组组合进入学习开发试验。最终冻结一组，正式消融仅移除新料/装料两项，其他一致。

这些权重不是物理定律。若裸墙出现“不施工更划算”，先报告目标失衡，不通过降低成功标准解决。回收料不得获得超过原成本的奖励，不鼓励搬来搬去套利。

### 7.2 处理不同动作持续时间

长刀与短刀耗时不同，不能只比较决策次数。采用半马尔可夫转移：一个策略动作持续Δt秒，折扣γ_t=exp(-Δt/1200)。这使同样60秒不会因为被切成更多段就改变总折扣。该1200秒时间常数是开发起点，可在600/1200/2400秒中用验证集冻结。

基础回报=负成本；终止时加100×实际达标-10×J_final。初始已合格场景的停止不计为完成施工的成功，不通过反复重置获得训练收益；各任务分层评估。

质量/保护使用势函数Φ(s)=-30J(s)-10P(s)，形状项γ_tΦ(s_next)-Φ(s)，真实终止时下一状态势取0。时间上限截断与任务终止分别处理：截断保留bootstrap及势函数，主动结束/硬失败才终止。GAE使用逐转移γ_t，λ先0.95固定并记录；该设计是待验证实现，需检查短长动作分段的回报一致性。

若保留旧的30ΔJ作历史基线，必须标明折扣与分段可能影响等价性；不能混用两种定义训练后直接比较回报数字。最终比较使用固定施工指标。

### 7.3 验收装料决策

“完全修整任务”专设零缺料、初始空刀且P0确认可修的场景：统计新增料量、装料频率和无料修整成功率。不能仅统计LOAD少，因为失败退出也会少装料。

统计每次LOAD后的多步质量变化，但不声称每份新料的贡献已精确追踪。反事实对照才用于检验“这一状态下装料是否比不装料好”。

## 8. 教师初始化、自主探索与训练预算

教师只提供基本可执行技能：空刀修棱、补薄区、带余料再利用、短中长路径、合理停止；每类允许不完美示范，同时明确记录最终是否改善。教师先选局部任务，再判断该任务所需材料与工具余料，不让全局缺料无条件抢占修棱。

初始化暂用200回合基础示教，按技能平衡采样；BC最多6000个优化step，每1000step检查可执行性，不要求达到教师轨迹相似度阈值。准入：开发集请求接触≥80%可执行，八类任务覆盖完整，有受控质量改善且无数值异常。

主组进入PPO后BC权重为0，不持续DAgger把策略拉回教师。仅允许开发阶段一次20回合的执行故障补课；使用则所有相关对照共享初始化并披露。后续失败若来自动作契约错误先修实现，不无上限收集教师数据拟合门槛。

探索保留操作与连续参数的熵，分别记录。归一化熵权重起点0.005/0.001，KL门限0.03、clip0.1、epochs4；lr在3e-6/1e-5/3e-5做有界开发试验。连续动作的掩码、混合分量和变换后的log概率必须有测试，不用未计入概率的随机强制动作冒充on-policy样本。[PPO原论文](https://arxiv.org/abs/1707.06347)支持所用优化框架，具体超参数是本项目待验证选择。

不因为某个动作失败就永久排除其邻域；失败图用于观测和分析，硬屏蔽仅针对确定不可执行约束。保留成功与失败样本用于分析，但历史经验不直接反复加入PPO更新。

### 8.1 课程

- 开发训练前20%采样：修棱/高点40%、缺料/裸墙30%、混合/粗糙20%、近完成/保持10%。
- 其后80%：固定八类任务等概率；统计实际物理时间分布和完成回合数，不能只看重置次数。
- 课程比例按累计有效采样数切换，不因某组表现不同而临时调整。随机化参数范围所有正式组一致。

### 8.2 单回合与总训练量

主评估固定3000秒施工预算，20 Hz等效60000控制步，最大2000次决策；长程诊断固定5000秒/100000等效步。取消按近期改善自动扩展的比较歧义，3000和5000秒两条曲线分开报告。主动失败退出允许但标失败；FINISH不操作和教师均接受相同预算规则。

主训练每更新8192有效高层转移，初选64环境×128转移；GPU环境数64/128/256仅在开发吞吐试验中选，正式固定。环境数变化时保持每次更新的总转移数一致并记录每环境时间跨度变化。长短动作另计累计材料子步/仿真秒数。

每组每种子累积预算：128更新=1,048,576转移；512更新=4,194,304；1024更新=8,388,608。三阶段是累计值，不相加。当前v9每核心种子819,200转移；新首档约1.28倍，中档约5.12倍，上限约10.24倍。不是在一开始承诺跑满上限。

先2个开发种子完成短试；正式3种子独立训练。128→512条件：物理/数值门禁通过，受控修棱出现稳定改善，裸墙补料不崩溃。512→1024条件：开发验证的最近128更新J改善至少5%，或任务成功率提升至少5个百分点，且材料损失/保护指标不恶化超冻结容差。比较组统一延长至同一预算，不能只给最好组追加资源后宣称方法优势。

若早停，报告实际预算、原因和全部已完成组，不能把部分矩阵包装成完整。学习效果差时优先定位，不靠无限延长试错。

## 9. GPU迁移与效率实验

### 9.1 先冻结参考，再改后端

创建三种后端：原始CPU参考、向量化CPU、PyTorch CUDA批量。GPU初版仅迁移训练代理，不宣称完整MuJoCo已GPU化。渲染与原生回放保留既有MuJoCo。

先对旧物理契约做迁移，避免同时改奖励/动作/材料。新动作依赖的采样分辨率变更，CPU/GPU均应用并重新冻结版本。若模型修复改变结果，记录physics_version，不混入纯速度比较。

### 9.2 GPU状态与执行

墙面[B,100,100]、工具材料[B,Hb,Wb]、边缘料珠、噪声、接触覆盖索引、状态掩码和预算长期驻留GPU。操作分组按mask执行，短中长轨迹分桶减少无效填充，结束环境独立重置。Python字典/集合改成固定形状索引及mask。

源环境仍保留CPU校验路径。工具覆盖同一墙面格子时，必须保持原来分摊和累加语义，不能并发覆盖丢量。材料计算FP32、守恒账本必要时FP64；先不开混合精度物理。CNN可另测AMP，但不能与后端迁移混成一个对照。

观测生成、优势计算和PPO采样尽量留在GPU；避免每步.item()/cpu()/numpy()同步。计时使用CUDA events和边界同步，预热单列。官方调优说明建议减少不必要同步：[PyTorch性能指南](https://docs.pytorch.org/tutorials/recipes/recipes/tuning_guide)。GPU索引累加需审计确定性，按安装版本检查可用算法：[确定性算法说明](https://docs.pytorch.org/docs/main/generated/torch.use_deterministic_algorithms.html)。

不把“用了GPU”表述成全部操作都并行；时间积分仍有前后依赖。优先通过多个独立环境并行扩大工作量。

### 9.3 数值等价门禁

同一冻结初态、同一动作序列、同一外部预生成噪声，测试100个单步接触案例及50条至少100动作的序列，覆盖加载、空刀、带料、边缘、换向、饱和、终止和域外材料。

暂定门槛：单动作墙面逐格厚度最大差≤0.01 mm；序列最大差≤0.05 mm；RMSE指标差≤0.02 mm；合格覆盖差≤0.5个百分点。守恒绝对误差≤max(0.01 mL,累计账本体积的0.01%)；无负厚度、NaN、材料凭空生成。

门槛附近事件单列：给定合格上下限附近像素数，检查分类翻转是否由容差解释。不得用“浮点误差”掩盖系统偏差。未通过则不进入正式GPU训练；临时用CPU版推进行为开发并报告性能线未完成。

### 9.4 性能对照与放行

固定预生成动作回放测试三后端，B=1/16/32/64/128/256；CPU额测进程数1/4/8/12/16/23和1/2个并行训练任务。覆盖装料、短/长接触、观察、终止，不用大量FINISH制造高steps/s。

每配置预热后测3次，每次至少120秒，独占测试或记录同时运行程序。报告中位数/P95耗时、有效CONTACT/s、模拟秒/s、环境子步/s、每秒高层转移及功耗/显存；再做至少50个更新的完整训练基准，记录初始化、验证和保存总时间。

正式GPU首选门槛：数值门禁通过、端到端吞吐相对优化CPU≥1.5倍、无采样质量下降或OOM；3倍为争取目标不是承诺。达不到时报告具体分项，不为占用率而扩大无用计算。功率/整机利用率不能代替实验进程贡献或有效样本量。

### 9.5 监测与日志

沿用5秒CPU各核/GPU利用率/显存/内存/功耗/温度监测，增加每阶段计时：材料、观测、可达筛选、等待/IPC、传输、推理、GAE、PPO、序列化、压缩、写盘、验证。计时开销用开启/关闭对照量化。

所有更新保留标量、梯度/KL/熵/clip比例、动作长度/装料分布、任务分层指标。逐动作保存动作、状态摘要和材料账本，分块二进制压缩；不要每条打开文件。完整大观测按分层固定抽样保存，每32更新保存完整rollout样本。若要求每条大观测均可重建，提供初态/随机流/动作日志并验证可重建性，不假装摘要等同原始观测。

checkpoint每32更新、阶段末和验证候选保存，含优化器、随机状态、环境快照、归一化和策略版本；后台有界队列加flush/校验，失败不得静默丢数据。非保存轮不重复序列化全模型。评估每32更新执行固定验证，端到端计时包含该成本。

先保持同步on-policy PPO，只异步日志。不直接让旧策略采样和新策略更新无限重叠；采样/学习流水线若以后启用，单立实验审计策略滞后。

## 10. 正式实验矩阵与归因

### 10.1 主比较

| 组 | 配置 | 回答的问题 |
|---|---|---|
| H0 | 冻结v9策略在原环境回归，同时在兼容的新评估环境做迁移测试 | 历史缺陷是否可复现；两种评估分开，不冒充同分布对照 |
| B0 | 新公共观测/奖励/终止契约，旧起终点几何，旧MLP，无新增料/装料成本 | 同预算重训的公共基线 |
| B1 | B0+新增料/装料成本 | 明确供料代价是否改善装料行为 |
| B2 | B1+方向/长度路径表达及短中长初始化探索 | 是否更容易发现有效长刀；属于组合改动，不声称只由参数化贡献 |
| B3 | B2+空间编码器，作为主方案 | 空间特征是否进一步改善局部缺陷判断 |
| C | B3+跨段连续接触，执行契约通过才训练 | 连续修整是否带来额外收益 |

B0–B3均3种子；主预算先各1,048,576转移，总12,582,912，再按统一规则扩展。C另计3种子，首档3,145,728转移。示教适配使用相同初态/物理轨迹，转换编码；初始化差异必须披露。H0是历史参照，不纳入严格算法增益归因。

### 10.2 必要消融与诊断

- B3去掉工具负载检查，退回指令历史估计：观察余料信息贡献。
- B3持续弱BC约束，与主组RL阶段BC=0比较：验证是否确有模仿束缚，不能先假定存在。
- B3去掉保护形状项：观察是否破坏已合格区域。
- 工具余料真值输入仅作能力上限诊断，不作为主成果。
- C可选；清刀D后置，不在未实现时预留一个“成功结果”。

必要消融先1种子筛查、同首档预算；准备正式因果结论时补齐3种子。只有1种子时只能称探索性结果。若要把参数化与长度探索分开归因，追加2×2对照；不做则保留“组合改进”表述。

GPU效率对照在相同B3配置、相同动作脚本和相同样本预算下进行，不需要将全部矩阵在两后端重训。至少做一组CPU/GPU短训练一致性检查，性能和最终随机策略完全逐位一致不是同一要求。

## 11. 数据划分、选模与验收

使用新的场景清单，不复用已经反复查看的60090等场景作为独立测试。历史案例只放回归集。建议开发100场/类、验证20场/类、测试30场/类，即800/160/240场；生成前检查已有seed与场景hash去重。独立随机流分别控制初态、材料、观测和策略，保存场景数组与hash。训练随机生成不读取验证/测试清单。

训练种子11/22/33是优化随机种子，不等于场景seed。正式测试在方法、预算、权重及选模规则冻结后一次性执行；观察后调参需下一修订及新测试集。

选模采用固定验证：先满足数值/执行门禁，再比较“需施工场景成功率”，并列比较J，再比较新料量和损坏率。不以训练回报或最漂亮视频选模。无达标模型时仍输出最佳候选，但明确质量失败。

最终代理评估各组每种子240场；主方案及教师/旧基线做完整MuJoCo验证，先固定分层24场（每类3场），通过后扩展至固定80场（每类10场）。若物理阶段失败，仍保留24场全部证据并报告未完成80场，不能拿名义结果代替。

### 验收项目

| 项目 | 预设目标 |
|---|---|
| 绝对施工质量 | 目标区及边缘合格覆盖≥95%，RMSE≤0.5 mm，P95误差≤1 mm，全部同时满足 |
| 边缘空刀能力 | P0确定可无料修整的独立场景中，至少90%不新增装料；同时报告修整成功率，不能用退出达成 |
| 修整实效 | 边缘任务成功率≥80%，初始合格区域最终损坏≤2个百分点（作为分层指标） |
| 裸墙能力 | 独立报告成功率；阶段目标先≥50%，未达到不称“完整涂墙流程已解决” |
| 超越教师 | 相同施工预算下边缘覆盖至少+10个百分点、RMSE降低≥15%，总体覆盖不下降、单位面积新料不增加；报告不满足项 |
| 行为证据 | 长刀或连续接触实际执行，有配对反事实显示改善；仅出现新轨迹形状不算新技能 |
| 数值/物理 | CPU/GPU等价门禁；完整MuJoCo无穿墙、轨迹跳变、明显跟踪失效，沿用冻结硬限制 |
| 性能 | 数值等价前提下端到端≥1.5倍，报告失败与收益区间 |

每个种子分别报告，并计算相同场景配对差；置信区间分层处理训练种子与场景，不把240场当240次独立训练。三种子不充分支持稳定性的强结论；论文前可增加独立种子，但需预注册并保留原结果。

## 12. 可视化：看完整过程，也看每次判断

原生MuJoCo为主要交付，不使用Web替代。每个录像/回放显示任务类型、初始是否已有料、工具估计/真值（真值明确仅调试）、新增料累计、当前操作、请求/有效接触长度、模拟时间、覆盖率/RMSE和退出原因。

20cm目标黄框、26cm缓冲绿框、50cm计算域外框必须有图例；增加刀路和接触状态显示，可关闭以避免遮挡。时间轴按记录推进，显示插值不能冒充物理子步。

每次正式运行交付：裸墙完整一回合、空刀修棱、混合高低、接近合格保持、最好/中位/最差案例，以及教师与主模型同初态对照。回放必须从初态到终止，不把局部片段命名为完整成功；无完整成功则明确标为失败，提供全部过程。

针对装料疑问增加同初态“补料/不补料”成对回放；针对短刀疑问增加“短/长路径”成对回放。额外反事实仿真计入诊断成本，不混入独立测试成绩。

## 14. 阶段交付与停止规则

1. P0：受控可解性、装料反事实、长度收敛、分项性能报告。交付“能不能修、哪里慢”，未通过不烧长训练预算。
2. P1：CPU公共环境与观测/动作/奖励契约、边界与回报测试；产生冻结设计修订。
3. P2：GPU等价与性能验证，选择环境批量，记录完整预算估算；失败时回到CPU开发，不称GPU已完成。
4. P3：有限教师初始化、短RL两开发种子、冻结超参数/课程/选模/预算规则。
5. P4：B0–B3主矩阵三种子，按规则扩展；C及消融独立记录预算。
6. P5：冻结选模、独立代理与完整MuJoCo评估、因果回放、最终报告。

不在此时承诺几小时或几天完成：先用P2测得端到端有效吞吐，按总转移数加验证/保存成本估算，并保留失败重试预算。开发试验、示教收集、失败及反事实分支与正式PPO分别统计，避免只报主更新量低估资源消耗。

新增行为、绝对施工达标、GPU加速是三个独立结论；可能只达成其中一项。最终报告逐项写通过/失败/未做，不把训练跑完等同实验成功。

## 15. 相比v9的改动与理由总表

| 改动 | 原因 | 要排除的误解 |
|---|---|---|
| 先空刀与不同料量反事实 | 不先假定装料/刀路哪个有错 | 看到失败就只怪上层网络 |
| 新料与次数直接成本 | 当前装料即时成本弱，后果延迟 | 把不装料本身当成功 |
| 可观测的工具检查与余料不确定度 | 指令历史估计漏掉刮回材料 | 给策略精确仿真余料却宣称可部署 |
| 方向/长度参数化 | 更容易沿“刀长”这个轴探索 | 强制最长、奖励长路径 |
| 空间编码器独立组 | 局部缺陷保留位置与结构 | 加大网络等于解决物理问题 |
| 连续接触后置独立组 | 跨段行为超出单刀接口 | 名义连续但实机规划仍每段撤离 |
| 示教仅初始化，有限补课 | 保留基本执行能力又允许离开教师分布 | RL1失败都来自持续BC |
| 按持续时间折扣与固定评估预算 | 长短动作公平比较 | 多切几个动作就改变收益 |
| CPU/GPU物理等价门禁 | 性能改造可能改变接触数值 | GPU更快就一定正确 |
| 分块记录与后台保存 | 当前未分类开销约26%值得剖析 | 以提高效率为由不留中间证据 |
| 任务分层与初始合格场景单列 | 防止提前结束伪装施工成功 | 平均覆盖好就代表裸墙能完成 |
| 冻结范围与完整失败交付 | v9已经证明跑完不等于成功 | 降门槛或挑漂亮回放宣称突破 |

## 16. 术语说明

反事实：把同一状态复制两份，一份加料、一份不加料，其余条件相同，观察差别。

半马尔可夫：一个动作可能持续几秒或几十秒，因此学习时也考虑它占用了多少真实模拟时间。

on-policy：PPO本轮主要使用当前策略刚采出的经验，不把大量旧策略数据随意混入。

等价迁移：GPU与CPU执行同一数学/材料规则，允许冻结容差内的数值差异，不允许悄悄改变墙面行为。

超越教师：相同初始状态和预算下效果更好，并有统计及行为证据；不是动作长得与教师不同。

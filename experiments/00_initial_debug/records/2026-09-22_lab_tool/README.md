软件会话，证据等级 L1。没有连接机械臂。照片标注用于建立几何模型，不表示运动学、动力学或实体工具已经标定。

## 如何查看

在仓库根目录双击 `实测末端工具仿真.cmd`。窗口是 MuJoCo 原生查看器。
右侧 Control 可调整六轴目标；J 开关 J6 ±30° 慢速往复，Z 回到模型 HOME，空格暂停。
这是纯仿真入口，不包含 USB/串口控制。HOME 是模型坐标零位，对应固件 [0,0,90,0,0,0]。

```powershell
.venv-loop/Scripts/python.exe tools/simulation/inspect_lab_tool.py
.venv-loop/Scripts/python.exe -m dummy_loop.wall scene --tool-profile lab_20260922 --out experiments/00_initial_debug/runs/lab_tool/scene.xml
```

也可在基础 `wall demo` / `wall collect` 上显式指定 `--tool-profile lab_20260922`。
这些基础控制接口接受新模型；本次不声称已验证新工具的墙面施工成功率。
当前 `wall_cycle`、旧训练启动器、旧策略、旧可达表继续使用原几何；不能直接把旧成绩迁移到新模型。

## 夹具方案（仿真设计）

保留照片中的顶部转接板，新增蓝色68×46×6 mm底板、双支撑和两道椭圆抱箍。
两道抱箍宽9 mm，沿木柄轴分布于夹持中心的 -27 / +22 mm 处，避开黑色立柱。
抱箍按对应位置的渐变椭圆截面留0.3 mm径向间隙、3.5 mm壁厚；分为可拆上下半环。
夹持中心选在刀片面积形心，使J6轴尽量经过刀面形心，减少偏心载荷。
减速器壳体连接link5，输出法兰、转接板、夹具、木柄和刀片连接link6。

安装孔距、孔径、螺栓规格、打印材料、嵌件、夹紧预载和强度均未确认。
模型中的耳部是布置占位；没有交付可直接打印装机的工程图。没有虚构已安装的实体力传感器。
照片中的圆弧刀尖采用直线肩部近似；基础材料模型仍以外包络估算覆盖，并非精准刀形砂浆模型。

## 动力学修正与兼容性

新模型同时设置J6执行器forcerange和关节actuatorfrcrange。旧模型只调执行器时仍会被关节直驱上限截断。
候选MINIF08-30参数图的额定值0.9 N·m用于本次模型上限，不能当作已测关节持续输出能力；效率、速度曲线和伺服刚度尚未辨识。
壳体质量放入独立固定子body，否则往已有显式惯量的link5添加geom，其质量不会自动并入旧惯量。

新法兰到接触面70.5 mm；模型HOME下TCP相对旧配置外移40.5 mm。
这依赖50 mm减速器总长等暂定值，不是实体TCP标定。旧可达区、旧策略分数不能用于新模型。
保留默认legacy配置是为了复现既有实验；新配置通过命名参数显式加载，不改写任何历史实验或实机配置。

# 末端抹刀 + D435 转接头 V1

2026-09-24，软件/CAD 会话，证据 L1。第一版配合样件，不是已验收承载部件。

## 交付与结构

- models/01_main_body.stl：主体 1 件，底板 + 两个下抱箍 + 一体相机支臂。
- models/02_tail_cap.stl：木柄粗端上盖 1 件。
- models/03_tip_cap.stl：木柄细端上盖 1 件。两盖内径不同，不要交换。
- models/04_fit_coupon.stl：38×38×8 mm 试孔件 1 件。
- 每个零件均有 STEP；adapter_assembly.step 为安装坐标的三零件装配。
- reference_fit_NOT_FOR_PRINT.step 包含抹刀和相机的简化包络，仅供装配参考。
- assembly_preview.png、detail_preview.png 为装配/爆炸预览，dimensions.png 为孔位图。
- parameters.json + build_model.py 是可修改的生成源，尺寸单位全部为 mm。

采用用户指定的平底连接方案：现有金属盖板保留，打印件贴在其上方，四颗螺钉从金属盖板下方穿过并拧入打印件底部的热熔螺母。不是替换金属盖板直接连接减速器。安装时可能需先拆下盖板装螺钉；需要检查底部螺钉头与减速器的空间。中间三个减速器连接孔由现有金属件承担，本设计不猜测或重复制作。

## 打印与装配建议

1. 先打印试孔件。四角Ø3.2通孔用于对照实物26×26孔距；中排沿X由左到右为Ø4.0、4.2、4.4盲孔，选定实际螺母及打印材料后试热熔。孔径不合适时修改 insert_pilot，螺母长度变化时同时调整 insert_depth 与底板厚度，不强行压入。
2. 第一版建议用PETG做配合样件，0.2 mm层高、5圈墙、至少5层顶底、40–60%填充作为起始设置；孔周局部实心。以上是工艺起点，不是经承载测试的标准。
3. 主体STL已平底落在Z=0；相机悬臂和抱箍耳下方需切片器生成可拆支撑，避免在热熔孔内生成难清理支撑。两上盖STL已侧放，圆弧轮廓平行打印平台，厚度9 mm，可减少拱形悬空。STEP保留装配坐标。
4. 共需8颗M3热熔螺母：底部4颗，下抱箍4颗。底部螺母由平底面装入，抱箍螺母由上方装入。以螺母厂家推荐底孔/热熔温度为准。
5. 抱箍初选M3×10螺钉4颗：盖耳5 mm、分口0.8 mm，理论咬合4.2 mm（不含垫片）。加垫片或分口压缩后须重新核对，避免触底。夹紧时交替均匀收紧；若盖子已闭合而木柄仍松，使用约0.3–0.5 mm薄防滑衬片或缩小孔径，不能靠继续拧紧硬压解决。
6. 底部连接螺钉长度按“实物盖板穿过厚度 + 垫片 + 约4–5 mm咬合”选定；未知盖板厚度，未固定长度。确认中间螺钉头低于四角支承平面。若高出，当前平底会干涉，应调整盖板紧固方式或共同增加平垫支承，不能强行压合。
7. 相机初选M3×8螺钉2颗：穿过6 mm板后进入相机约2 mm，无垫片计算。按实际打印厚度/垫片复核，最长进入量3 mm。相机镜头朝工具材料面方向，侧边USB线需留独立松弛回路。
8. 先离线试装：核对孔距、盖板支承、木柄滑移和相机连接。再静态加载评估支臂挠度、抱箍抗转及热熔螺母拉脱。未做有限元或负载试验，不给出安全工作力或可直接涂墙的承载承诺。

## CAD 验证与复现

cad_checks.json：4个零件均为有效单实体；主体/上盖无相交体积；估计木柄、相机包络无穿插；四角孔为空且有封底，相机孔贯通。检查基于理想CAD，不含打印误差、实际金属盖板、夹紧变形、材料、热熔过程或紧固件。

复现环境：Python3.12，cadquery2.8.0，matplotlib3.11.2；首次建独立虚拟环境并安装 requirements.txt，再运行 `python build_model.py`。本机独立环境为 D:\VLA\_tools\cadquery-env，不修改训练环境。变更 parameters.json 后重建会覆盖本设计目录的生成模型，重要试制版本应复制为v2或新的版本目录。

后续优先实测：改良盖板四角孔距与支承高度、螺母实际规格、木柄两个夹持区截面、相机后壳孔距。工具参数未改变；新增的是打印件可制造几何与明确装配方式。

# v0.8边缘精修与延长训练建议

分析会话，L1静态代码与training.json分析，非新实验结果。用户允许评分区外一定范围涂抹。

v08_manual：基础预算60000、最高100000、最大2000次决策。选中PPO在完整MuJoCo20局平均11297.1步，11局finish、9局stall；表环境60局26finish、33stall、1budget。因此优先修提前结束，非继续增大上限。教师plateau_n=25会在未成功时FINISH；环境stall_window=20、stall_limit=1、min_cycles=60。FINISH失败处罚仅2；继续工作存在负成本，可能鼓励早退，需控制对照验证而非认定唯一原因。

表教师/选中PPO：合格覆盖46.91%/33.48%，RMSE0.997/1.597mm，边缘合格43.65%/29.87%。联合仿真对应全域31.06%/24.04%，RMSE1.934/1.904mm，边缘29.01%/24.22%。教师提升未完整传给学生，代理与执行差距仍在。粗糙度已进入quality_cost，不应称当前完全无平整度奖励。

建议：固定200mm验收区，扩大持久材料缓冲区，候选单侧30/50mm，按工具扫掠和机械臂可达确认；完整记录域外材料，重建相关可达数据。补料、整平、边缘精修三阶段可回退；凸起横切、边缘平行、越边收刀候选竞争，以预计前后质量变化选动作，勿默认全推最近边界。保留已合格区的损坏惩罚，加入边缘过厚体积、P95超高、分带粗糙度及缓冲区堆料诊断。参数待消融。

先建立凸棱/角落堆料/邻近凹坑/已合格边缘的技能测试，验证材料模型与接触控制能改善；再训练精修BC/DAgger，注意连续回归混合多方向平均问题。终止分别记录success/give_up/stall/budget，平台期先触发重扫/换方向/换技能等有限恢复，不允许无限循环或谎报成功；只改标签不足。保留预算，测试现停滞窗口20对40、教师平台期25对50（试验值）；公平对比质量-时间曲线。

网络训练可将50×2048扩为分阶段100/200/400轮：204800/409600/819200高层决策步，早期验证无退化再延长，按独立验证选最优而非末轮。长程目标需检查gamma=.99、每动作成本与最终质量收益的尺度和时间语义。先做教师和BC门禁，再长PPO，保持旧基线与独立测试。无承诺提速或成功率。

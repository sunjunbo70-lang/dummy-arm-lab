# 2026-09-20 末端改为：J6 减速器 + 3D 打印抹刀座 + 日式尖头抹刀（刚性）

证据等级 **L1**（仿真）。未连接机械臂，未发送任何运动指令。

## 实际方案（用户说明 + 照片）

现有的末端是「J6 电机 → J6 减速器 → 夹爪电机 → 夹爪」。后续方案：去掉夹爪电机和夹爪，只保留减速器；
在减速器输出法兰上装 3D 打印的抹刀座，卡住抹刀的木柄。抹刀是日式尖头抹刀：长条钢刀面，一头尖一头方，
刀面背面一根立柱连到与刀面平行的木柄。**整个末端是刚性的，没有伸缩或回弹。**

此前仿真里的「弹簧滑轨 + 矩形刀面」是早期设计假设，不是实物，现只作为 `--tool spring` 对比保留。

## 结果（30 组随机误差，同一随机种子；`raw/study/sensitivity.json`）

| 补偿 | 平均覆盖率 | 最差 | 压力在 2–15 N 内的时间占比 | 最大接触力（最差一组） |
| --- | --- | --- | --- | --- |
| 无（只按位置压入 1 mm） | 0.378 | 0.000 | 0.34 | 141 N |
| 仅力闭环 | 0.867 | 0.408 | 0.83 | 133 N |
| 仅探触 | 0.658 | 0.179 | 0.43 | 93 N |
| 探触 + 力闭环 | 0.893 | 0.654 | 0.73 | 47 N |

无误差时：只按位置压入覆盖 0.73、最大力 58 N；探触 + 力闭环覆盖 0.98、最大力 26 N。
单因素：墙比名义近 5 / 10 mm 时只按位置压入的最大力 93 / 114 N（探触 + 力闭环 23 / 22 N）；
J2、J3、J5 单轴零位误差 1–2° 时探触 + 力闭环覆盖 0.84–0.97；最敏感的是伺服偏软（kp × 0.5：0.74）
与摩擦偏大（× 1.7：0.71），延迟 3 个周期时峰值力升到 51 N。录制 4 条样本，回放 4/4 逐位一致。

## 结论（仿真设计结论，待实机验证）

1. 刚性工具下接触力由位置误差和未辨识的关节伺服刚度决定。刀面变小后接触面积小，同样的位置误差顶出的力更大
   （只按位置压入，最差 141 N）。**法兰与抹刀座之间的力传感器是必需的**：用它做开工前探触和抹涂时的压力闭环。
2. 即使探触 + 力闭环，压力也只有约 73% 的时间落在 2–15 N 内，峰值仍可到 47 N。实机上要：低速接近墙面、
   力闭环增益从小往大调、设一个硬性的力上限（超过即停），并先在台架上测关节伺服刚度。
3. 刚性刀面对角度误差敏感（关节零位误差会让刀面一边先贴墙）。M3 做好 J2、J3、J5 零位标定；
   或在抹刀座与木柄之间留一点被动自适应（小角度橡胶垫），让刀面自己贴平。
4. 夹持点放在刀面形心正上方，拖曳力对 J6 基本不产生扭矩。当前形心正好在木柄靠刀尖的一端，
   抹刀座夹块会略超出木柄端头；如果实物不便这样夹，夹偏后 J6 要承受「拖曳力 × 偏心距」的扭矩。

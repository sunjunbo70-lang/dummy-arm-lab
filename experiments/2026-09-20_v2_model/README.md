# 2026-09-20 仿真切换到 Dummy V2 模型

证据等级 **L1**（资料 + CAD + 软件测试）。未连接机械臂，未打开串口，未发送任何运动指令。

## 目的

用户实机是 Dummy V2，末端是 J6 电机裸轴。此前的仿真建在 auk 参考模型上（尺寸、减速比、零位都不是 V2，末端是法兰）。
本次把仿真链路换成与 V2 资料一致的模型，并重跑依赖模型的分析。

## 做了什么

1. `dummy_loop/v2.py`：V2 固件 DH、HOME、V2 限位与减速比、逐关节电机/减速器/皮带配置、资料冲突清单，
   以及固件 `SolveFK` 的逐行移植。
2. `tools/modeling/build_dummy_v2.py`：从 V2 装配体 STEP 生成 `models/dummy_v2.xml` + `meshes_v2/`。
   用减速器中心把 CAD 对齐到固件坐标；按子装配把 318 个实体分到 7 个连杆；从 J6 电机实体中按半径拆出 Φ5 输出轴作为 link6。
3. 墙面仿真（`dummy_loop/wall/`）、实机同步上位机画面、`view_simulation.py` / `六轴同时往复仿真.cmd` 改用 V2 模型。
   BC 冒烟闭环仍用参考模型，历史数字不变。
4. 重跑：布局搜索、30 组随机误差的补偿对比、4 条录制与回放、静力矩（带 V2 额定值对比）。

## 结果

- 模型正运动学与固件 SolveFK 在 302 个姿态上一致（误差 < 1e-9）。零位 = HOME，关节角 = 固件角 − HOME。
- 估计总质量 3.73 kg（运动部分 2.86 kg）。裸轴 Φ5.0 mm，轴端距腕心 73.4 mm，露出外壳约 13 mm。
- 布局：27/96 可行；最优为墙距 40 cm、工作区中心高 15 cm、刀面垂直于 J6 轴（默认已改为此值）。
- 补偿：平均覆盖率 无 0.934 / 闭环 0.944 / 探触 0.980 / 两者 0.980；最差 0.350 / 0.760 / 0.917 / 0.925。
- 静力矩：压 10 N、拖曳系数 1.0 时 J2 约 5 N·m，超过 MINI11-50 额定 3.5 N·m；J5 约 3.0 N·m，接近 MINI8-50 峰值 3.3。
  J6 直驱只有约 0.07 N·m 可用，刀面必须与 J6 同轴。
- 回放：4/4 逐位一致。测试 70 → 78 个，全部通过（3 个按设计跳过）。

详细讨论见 `docs/SIMULATION.md`「V2 重跑」与 `docs/hardware/DUMMY_V2.md`。

## 局限

见 `run.json` 的 `limitations`。最重要的两条：所有 V2 参数都是**候选值**，M3 实测前不写入 `configs/`；
J6 减速比资料冲突（截图 5 / 装配体直驱）未解决，M3 必须先用 ≤5° 小角度测 J6。

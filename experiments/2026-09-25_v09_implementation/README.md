## 已发现并修正的执行器问题
1. 原关节目标阶跃，移动时长只是等待。新执行器在物理步内连续插值目标。
2. REUSE/LEVEL实际从扫描位出发，却接到以装料位为起点的搬运路径。现在先从实际姿态连续进入起点。
3. 使用朝上待机位作为相机代理阶段的扫描姿态，避免无必要的竖直待机。这不等同于验证实体 D435 在该姿态能观察墙面。
4. 材料搬运积分读取执行中的实际法向，替代段末姿态近似。诊断记录用实际模拟秒，新增原生 MuJoCo 时间戳回放。

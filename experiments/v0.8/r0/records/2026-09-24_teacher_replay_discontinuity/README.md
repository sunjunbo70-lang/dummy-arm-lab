# 教师闪现与训练影响审查

L1已有轨迹数组与源码检查，无重新仿真。v08_teacher_preview/rollout.npz中相邻帧任一关节差>10度共179处，最大48.3415度，最大多发生SCAN→下一决策CARRY_FACE_UP。

view.record把SCAN设为ex.q_scan名义姿态，并合并ARM_TRACE/事件。arm._run在内部多次mj_step后才mark一个终点，不记录全部动态子步；trace无时间戳，view固定每帧0.05秒。这使真实非等间隔端点被当等间隔帧显示，q_scan替换实际末态又可引入额外不连续。48度是显示采样差，不能据此推断实体/模拟瞬时速度48度每50ms。

当前BC使用env._observe与teacher_action高层动作，PPO用环境obs/action/reward，均不是从此视频/rollout学习像素或相邻关节帧；训练默认table执行器。因此显示跳帧不会直接成为视觉特征标签。但执行/材料耦合仍有风险：transport在每段_run后以终点face_up代表整段dt，不能证明保料损失逐子步精确；回放未反映完整时间也不能用于速度验收。

建议独立修复：真实时间戳、按固定模拟时间采集q及必要材料状态、统一事件排序、SCAN使用实测末态、按真实时间播放；不靠纯插值掩盖问题。随后审查材料transport随子步姿态积分及表/完整执行差异。旧轨迹保留。当前结论只排除直接视频输入污染，不证明物理训练完全无误。

# PPO 动作可视化（软件会话，L1）

目的：直接观看已训练强化学习模型在墙面涂抹任务中的真实仿真动作及逐步形成的材料层。

输入：根目录外 `plaster_update` 更新包中的 RL 代码和两份已训练权重；主仓库此前未合入。
按文件哈希对比后合入现有更新包，保留所有原实验，新增可视化模块和双击启动器。
目录盘点位于 `raw/file_inventory.json`，记录 567 个文件的路径、大小与哈希；
不包含虚拟环境、Git 内部文件、缓存及运行输出。压缩包、CAD 等二进制做资产盘点，
本次详细阅读重点为工程约定、状态文档、场景、控制器、训练、材料、整片执行和测试代码。

执行命令和环境：见 `run.json`。Python 现有 `.venv-loop`，不安装额外依赖。

结果：手法预热模型三刀整片覆盖 0.9796，厚度 RMS 0.371 mm；平刀预热 0.9796、0.819 mm。
两份渲染轨迹的每一帧 qpos 与厚度场都与独立无渲染重跑 **逐元素完全相同**，见
`raw/replay_verification.json`。全套 102 个测试完成，3 个按已有设计跳过。
浏览器内核对了暂停、逐帧、进度拖动、策略切换与实际渲染画面。

查看：双击项目根目录 `强化学习动作可视化.cmd`；也可直接打开
`outputs/wall/ppo_visualization_v2/index.html`。静态证据及 GIF 在 `raw/technique/` 和 `raw/flat/`。

失败与局限：首次 v1 渲染相机在墙背面，画面不可用，保留于 outputs，v2 已修正并视觉复核。
条带间过渡采用原实验的 reset，明确标注；不是完整连续施工轨迹。
砂浆为高度场代理，不是流体模拟；无实机运动或验证。

下一步：如需连续横移和上料动作，应另外完成过渡轨迹规划，不能靠渲染插值伪造。

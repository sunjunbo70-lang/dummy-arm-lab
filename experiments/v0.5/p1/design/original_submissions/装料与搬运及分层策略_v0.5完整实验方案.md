## 0. 新一轮实验要回答的问题

本轮不只回答“刀面朝上搬运是否更少掉料”，而要同时回答四个层次的问题：

1. **材料物理层**：在给定砂浆流变参数和界面属性时，装料、空中搬运、转腕、接触和离墙过程能否满足质量守恒，并产生方向正确的材料迁移？
2. **技能执行层**：机械臂能否连续完成 `装料→抬升→搬运→预接触→立刀→接触→涂抹/整平→离墙→回收`，而不是依赖不连续的几个 IK 点？
3. **高层决策层**：策略能否根据墙面缺陷选择装料、竖抹、横抹、斜抹、交叉整平、旋转工具、重扫或结束，而不是退化为反复竖直涂抹？
4. **学习动作层**：确定性技能执行器能否成为 VLA 的示范教师，并允许后续 VLA 通过动作块或残差学习改进轨迹，同时保留碰撞、限位和力控安全层？

因此，本轮按“物理基础→确定性技能→高层学习→VLA 接入”逐级推进。前一级未达到验收门槛时，不启动后一级大规模训练。

## 1. 关键物理假设及其正确表达

### 1.1 墙面比光滑金属工具更容易留住砂浆

本方案接受以下**方向性工程先验**：对于本项目预期的粗糙、具有孔隙和吸水性的砖墙/水泥基墙面，以及相对光滑的金属抹刀承料面，砂浆离刀时留在墙面的比例应大于留在工具上的比例。

这项判断有合理的材料学基础：墙体表面的粗糙结构可产生机械咬合，孔隙和毛细作用可改变界面接触及水分迁移；已有水泥基材料研究也显示基底粗糙度、孔隙/吸水能力、含水率和材料流变会显著改变界面黏结。它并不意味着任意墙面、任意含水率、任意金属表面下都必然满足同一固定比例。

因此，v0.5 不再使用“完全对称的 0.5”作为主要假设，也不把“0.75”写成已被实测证明的常数，而采用以下受约束模型：

```text
alpha_wall = A_wall / (A_wall + A_tool)
约束：alpha_wall > 0.5
名义值：alpha_wall = 0.75
仿真随机化范围：0.60–0.90
敏感性点：0.50 / 0.60 / 0.70 / 0.75 / 0.80 / 0.90
```

这里的 `alpha_wall` 对应当前 `lift_wall_fraction` 的物理含义：刀具离墙时，夹层材料有多少留在墙上。`0.75` 可以继续作为名义值，因为它表达了墙面优先留料的明确先验；敏感性分析用于判断算法优势是否只在某个特定数值下成立。

### 1.2 为什么仍然需要扫描，而不是直接固定 0.75

扫描不是否定“墙面附着更强”，而是区分两件事：

- **方向关系**：`alpha_wall > 0.5`，这是本轮采用的工程先验；
- **强度大小**：究竟是 0.60、0.75 还是 0.90，目前没有本项目材料与表面的剥离/留料实验。

如果策略在 0.60–0.90 全范围都优于旧方法，可说明结论对界面参数稳健；如果只在 0.90 有效，则说明策略依赖过强的理想化墙面吸附，不能直接外推到实体施工。

### 1.3 当前模型只是离墙分配模型

`lift_wall_fraction` 不能替代真实的双界面黏附模型。它只描述离墙瞬间的材料分配，不包含：

- 墙面和金属表面的独立黏附应力；
- 法向剥离与切向滑移的差异；
- 接触时间、法向压力和实际接触面积；
- 墙体吸水、表面湿度、污染和砂浆静置时间；
- 界面破坏与砂浆内部内聚破坏之间的竞争。

因此 v0.5 采用两级实现：第一阶段使用受约束的 `alpha_wall` 代理；获得实体数据后，升级为 `tau_adh_wall`、`tau_adh_tool`、法向剥离阈值和接触历史共同决定的双表面模型。

## 3. 几何、质量与坐标基准

### 3.1 不再混用三种长度

必须分别保存：

1. `flange_to_contact = 70.5 mm`：输出法兰安装面到抹刀接触面的工具尺寸；
2. `reducer_installed_height`：J6 电机侧安装面到输出法兰面的减速器/转接件装配长度；
3. `tcp_delta_vs_legacy`：相对于指定旧模型版本的 TCP 变化量。

当前 `lab_20260922.json` 仍以图纸与估计转接件得到 `j6_reducer_length=33.5 mm`，同时证据字段保存了用户粗测约 `28 mm` 的冲突数据。v0.5 不把任一值伪装成已确认真值：

- 名义几何运行使用当前配置值，保证已有测试可复现；
- 几何敏感性使用 28.0、30.75、33.5 mm 三档；
- 在实体游标卡尺测量完成后再更新标准值；
- 所有实验产物必须记录实际使用的三种长度和配置文件哈希。

### 3.2 末端质量配置

建立两个明确 profile：

- `lab_tool_no_camera`：抹刀、夹具、转接板、减速器；
- `lab_tool_wrist_d435`：上述部件加 D435 和延伸支架。

相机与支架当前约 0.10 kg，且存在约 70 mm 的侧向偏置。它们会改变 J5/J6 静态力矩、惯量、碰撞包络和可达路线。动力学与可达性扫描必须分别报告两种 profile，不能只改变外观模型。

### 3.3 坐标定义

定义刀具坐标系 `B`：

- `x_B`：沿刀片长度，从刀尾指向刀尖；
- `y_B`：沿刀片短边；
- `z_B`：承料面的外法向；
- 世界系 `z_W`：竖直向上；
- 墙面法向 `n_wall`：由墙面指向机械臂。

定义：

```text
face_up_score = dot(z_B, z_W)
wall_facing_score = dot(z_B, n_wall)
g_B = R_WB^T * [0, 0, -g]
```

这样横向、竖向和斜向运动都使用同一重力投影，不再依赖一个含义随路径方向变化的 `pitch`。

## 4. 阶段 A：工具配置接入与连续可执行性地图

### A1. 配置单一来源

`wall_cycle` 不再重复拼装散装工具参数，而从命名 profile 读取几何、质量、惯量、TCP、相机和力矩候选值。保留 `legacy` 入口，仅用于回归复现。

**理论逻辑**：同一物理实体若在场景生成、可达性扫描和训练环境中使用三份参数，任何实验对照都会被配置漂移破坏。

**验收**：同一 profile 在场景审计、可达性脚本和训练环境中输出完全相同的 TCP、总质量、质心和碰撞体列表。

### A2. 粗到细的连续轨迹扫描

第一轮扫描墙距 0.28–0.38 m、候选工作区和进料台位置；刀面姿态取 `face_up_score` 对应的 0°、15°、30°、45°、60°、75°、90°档。发现边界后再局部细分。

每个墙面工位不只测试终点 IK，而测试完整轨迹：

```text
feed_station
→ lift_clearance
→ carry_waypoint
→ wall_standoff
→ precontact_rotation
→ contact_pose
```

每条轨迹检查：

- IK 连续性和关节跳变；
- 自碰撞、墙面碰撞、料台碰撞、D435/线缆包络；
- 关节位置、速度、加速度限制；
- Jacobian 条件数或最小奇异值；
- 估计静态/动态关节力矩及余量；
- J6 累积旋转和回绕需求。

输出不再只用 full/partial/none，而保存：最大 `face_up_score`、最小碰撞距离、最大力矩利用率、最大关节速度利用率、奇异性指标和是否存在一条连通路径。

### A3. 作业区重算

只有“从料台出发并能连续到达、完成接触、再安全返回”的工位才算可用。基于这些工位计算最大内切矩形/正方形，再乘 80% 运行冗余。分别输出无相机和腕部相机作业区。

### A4. 阶段门槛

- 至少 80% 候选目标工位存在连续可执行路线；
- 运行区内最小碰撞距离大于预设安全余量；
- 所有关节峰值力矩利用率低于候选上限的 70%；
- 如果达不到，优先调整料台位置、墙距和路径，不进入训练。

## 5. 阶段 B：守恒装料与连续搬运材料模型

### B1. 料台状态

`FeedBoardModel` 至少维护二维厚度场、剩余总体积、材料年龄和局部流变参数。15 mm 可作为初始厚度，但它只是场景初值，不是决定一次装料量的规则。

### B2. 装料接口

```python
feed_step(
    blade_pose,
    blade_twist,
    normal_force_N,
    scoop_depth_m,
    contact_mask,
    dt_s,
) -> FeedStepResult
```

装料量来自工具扫过体积、接触压力、可供材料和流变约束。必须满足：

```text
料台减少量 = 刀具增加量 + 料台外损失量
```

**相对 v0.4 的改变**：删除 `g_n_feed=cos(carry_tilt)` 作为装料效率的主公式。重力投影仍参与材料在刀面上的保持和流动，但工具从料台取料主要由法向力、插入深度、扫掠距离和速度决定。

### B3. 连续空中材料更新

将 `air(pitch)` 升级为：

```python
air_step(
    blade_rotation,
    linear_velocity,
    angular_velocity,
    linear_acceleration,
    dt_s,
    stats,
)
```

刀面切向重力由 `g_B` 计算；旋转和加速造成的等效惯性作为后续复杂度逐级加入。第一版可先实现姿态和 `dt`，第二版再加入加速度项，但接口一次定义完整。

当前模型将超过屈服稳定厚度的流动近似为即时排出。v0.5 至少必须让结果对物理时长敏感、对离散步数收敛，不能让“调用几次”代替“经过几秒”。

### B4. 墙面—刀面不对称离墙

第一版实现：

```text
alpha_wall nominal = 0.75
training randomization = Uniform(0.60, 0.90)
counterfactual baseline = 0.50
```

第二版实体校准接口预留：

```text
tau_adh_wall, tau_adh_tool,
normal_peel_threshold,
tangential_slip_threshold,
contact_time, contact_pressure
```

### B5. 材料层单元测试

1. 全阶段质量守恒误差小于初始总量的 `1e-6`；
2. 相同 2 秒轨迹在 `dt=0.02/0.01/0.005 s` 下最终留料量收敛；
3. 整个场景绕重力轴旋转后，物理结果满足坐标等变性；
4. `alpha_wall` 增大时墙面留料比例单调不减；
5. `alpha_wall=0.5` 能复现旧对称离墙逻辑；
6. 料台、刀具、墙面、掉落和区域外材料的总账闭合。

## 6. 阶段 C：技能状态机与约束轨迹执行器

### C1. 新状态机

```text
LOAD            在料台建立接触
SCOOP           按规定力/深度/距离取料
LIFT_FROM_FEED  沿安全方向脱离料台
CARRY           承料面尽量朝上并避障搬运
PRECONTACT      到达墙前安全位姿
ROTATE_TO_WALL  在安全间隙内逐步立刀
CONTACT         低速建立目标法向力
APPLY/LEVEL     涂料或整平
SEPARATE        按受控方向脱离墙面
RECOVER/RETURN  回收余料、重扫或返回料台
```

### C2. 为什么增加这些阶段

- `SCOOP` 与 `LIFT_FROM_FEED` 分开，才能表达刮取成功但抬升时掉料；
- `PRECONTACT` 与 `ROTATE_TO_WALL` 分开，才能确保工具只在接近墙面前的安全区域立起；
- `CONTACT` 独立，便于力控缓慢建立接触，避免把碰撞冲击归因于涂抹策略；
- `APPLY` 与 `LEVEL` 使用相同接触物理，但任务目标不同；
- `SEPARATE` 决定最终材料留墙比例，是黏附模型直接作用的阶段；
- `RECOVER` 让策略处理失败，而不是失败后直接重置环境。

### C3. 轨迹表示

低层确定性执行器使用带时间参数的 SE(3) 关键帧轨迹，位置采用限加速度/限跃度插值，姿态采用四元数插值；接触阶段切换到位置—力混合控制。所有轨迹先经过约束检查再交给 MuJoCo 或实机控制接口。

### C4. 近墙旋转规则

刀具不能在任意位置瞬间从朝上变成朝墙。旋转起点由工具扫掠包络和墙面间隙共同确定：

```text
distance_to_wall >= swept_radius(tool + camera) + safety_margin
```

在满足该条件的最后一段路径中进行连续旋转，接触前速度降低到接触建立速度。

### C5. 教师技能库

建立参数化教师而不是单一路径教师：

- `load_and_carry_face_up`
- `apply_vertical`
- `apply_horizontal`
- `apply_diagonal_left/right`
- `level_cross_hatch`
- `reuse_remaining_material`
- `rescan_and_recover`

教师用于生成可解释示范和训练初始策略，不作为最终最优性的证据。

## 7. 阶段 D：高层分层策略

### D1. 输入表示

高层策略接收：

- 墙面目标厚度图、当前厚度图、误差图和置信度图；
- 墙面缺陷连通域及方向特征；
- 刀面材料二维分布、剩余体积和材料年龄；
- 关节状态、末端状态、接触力和当前技能阶段；
- 最近 K 次技能、参数、结果、掉料量和改善量；
- 每个工位/姿态/方向的连续可执行性掩码；
- 剩余时间、装料次数和失败计数。

二维地图使用 CNN 或轻量 ViT 编码，历史使用 GRU/Transformer 编码。单纯扩大 MLP 只作为消融组。

### D2. 混合动作空间

离散头：

```text
skill ∈ {LOAD, APPLY, LEVEL, REUSE, ROTATE, RESCAN, RECOVER, FINISH}
path_type ∈ {VERTICAL, HORIZONTAL, DIAGONAL_L, DIAGONAL_R, ARC, CROSS_HATCH}
```

连续头：

```text
start_uv, end_uv, curvature,
force_profile, speed_profile,
contact_pitch, carry_face_up_target,
rotation_start_distance, requested_load
```

离散技能使用 categorical 分布，连续变量使用 Gaussian/Beta 分布并映射到物理范围。避免将离散模式塞进高斯连续数值后再四舍五入。

### D3. 防止竖直动作塌缩

原 v0.3 教师明确偏向竖直方向，且 PPO 主要扩大力和倾角探索，路径方向探索不足。因此 v0.5 同时修改：

1. 教师示范在合法方向上平衡采样；
2. 为所有路径参数提供合理初始标准差；
3. 使用需要不同方向才能高效处理的缺陷课程；
4. 记录路径方向熵，但不直接为了“多样”而奖励随机动作；
5. 用任务收益判断方向：狭长横向缺陷应让横抹更优，斜向沟槽应让斜抹更优，局部高点应选择整平而不是继续上料。

### D4. 大模型规划器的位置

GPT、Gemini、DeepSeek 等闭源 API 可以作为候选技能规划器：输入压缩后的结构化墙面状态和视觉摘要，输出若干候选技能序列；本地价值网络、规则约束和可达性检查负责筛选。

API 模型权重不能由本项目直接强化学习更新，因此实验可优化的是：提示模板、状态编码、候选筛选器、记忆/检索和本地价值模型。若要训练决策模型，应使用可本地微调的视觉语言模型或训练专用高层策略网络。闭源大模型组应作为规划基线或教师，不应作为唯一可训练核心。

## 8. 阶段 E：VLA 动作生成与后训练

### E1. 初始职责

第一版 VLA 不直接输出电机电流，也不绕过安全控制器。推荐按难度依次尝试：

1. 预测下一组 SE(3) 关键帧；
2. 预测 0.5–2 秒动作块；
3. 在确定性技能轨迹上预测小幅位置、姿态和力的残差；
4. 只有前述方式稳定后，再研究更长时程端到端动作生成。

### E2. 数据规范

每个统一时钟时间戳记录：


## 9. 奖励设计

所有体积项先除以本回合供应材料体积，距离除以工作区尺寸，时间除以回合上限，使奖励项无量纲：

```text
R = + w_cov * coverage_improvement
    - w_rmse * thickness_rmse
    - w_rough * roughness
    - w_carry * carry_loss_fraction
    - w_wall * wall_slump_fraction
    - w_out * outside_fraction
    - w_force * force_violation
    - w_collision * collision
    - w_time * normalized_time
    - w_fail * recovery_or_abort
```

不直接奖励横向、斜向或旋转次数。方向多样性应由任务几何带来收益，否则模型可能学会无意义地切换动作来赚奖励。

分离三个损失来源：

- `carry_loss`：离开料台后、接触墙前的损失；
- `process_waste`：接触施工中的掉落和区域外挤出；
- `separation_loss`：离墙过程中从墙面重新带走或掉落的材料。

## 11. 评价指标

### 材料与施工质量

- 覆盖率、厚度 RMSE、最大局部误差；
- 表面粗糙度、条纹方向性、缺陷残留率；
- 搬运损失率、施工浪费率、离墙损失率；
- 单位有效覆盖面积的材料消耗。

### 规划与技能

- 技能选择准确率或相对启发式教师的收益；
- 各路径类型使用率和条件收益；
- 无效动作率、恢复成功率、完成时间；
- 连续路径规划成功率。

### 机器人可执行性

- 最小碰撞距离；
- 关节速度、加速度和力矩峰值；
- 接触力超调和稳定时间；
- IK/轨迹失败率和奇异性分布。

### 泛化与鲁棒性

- 未见缺陷形状、墙距、料台位置；
- 材料参数和界面参数变化；
- 深度噪声、遮挡和外参扰动；
- 工具质量、质心和减速器长度不确定性。

## 12. 分阶段执行顺序与停止条件

### Gate 0：配置一致性

完成工具 profile 单一来源和几何审计。配置仍混用时停止。

### Gate 1：连续可执行性

完成 A2/A3。若工作区覆盖不足或力矩/碰撞余量不够，先调整场景与支架。

### Gate 2：材料模型可信度

完成质量守恒、时间步收敛和界面敏感性。若结果随 `dt` 或采样点剧烈变化，停止 RL。

### Gate 3：技能教师对照

每个参数化教师至少运行 100 个固定场景。朝上搬运应显著降低 `carry_loss`，且不能以明显增加碰撞或时间为代价。

### Gate 4：高层策略

先跑 P0/P1/P2。只有 P2 在复杂缺陷集上显著提高任务收益，才说明空间—时序策略有价值。P3 大模型组随后加入。

### Gate 5：VLA

确定性执行器和数据质量通过后启动 V1–V3。VLA 必须在相同安全约束下比较，不能通过更宽松的碰撞/力限制获得表面优势。

### Gate 6：实体迁移

先做无材料低速轨迹，再做假材料/低风险介质，再做真实砂浆。完成相机外参、力传感器、工具质量和材料台架标定后，才评价 sim-to-real 性能。

## 14. v0.4→v0.5 逐项变更理由摘要

1. **保留墙面附着更强的假设，同时加入区间和反事实基线**：方向先验合理，但具体数值尚未由本项目测量；这样既不退回不合理的对称模型，也避免将 0.75 当作事实。
2. **把 `carry_tilt` 改成完整姿态和两个可解释分数**：复杂施工包含横向、斜向和旋转，单一俯仰角不具备坐标一致性。
3. **静态 IK 改成连续轨迹可执行性**：机械臂事故和失败通常发生在姿态切换途中，而不是目标点本身。
4. **装料由接触过程决定**：法向力、刮取深度和路径才是主动取料机制；重力主要约束取料后的保持。
5. **固定采样次数改成时间积分**：物理损失必须随运动时间和动态状态变化，并对离散步长收敛。
6. **状态机细分**：为材料损失、碰撞、接触冲击和恢复提供可定位的原因标签。
7. **高层采用混合动作头和空间—时序编码**：解决离散模式表达含混、地图结构未被利用和竖直动作探索不足。
8. **不立即用 VLA 替换全部控制**：先用可靠执行器生成数据，VLA 学关键帧/动作块/残差，减少端到端训练的样本和安全风险。
9. **加入四层消融**：否则无法判断改进来自材料模型、技能规则、决策网络还是动作生成模型。
10. **把实体不确定性写进 profile 和随机化**：减速器长度、质量、相机偏置尚未完全测准，必须显式传播到结论范围。

## 15. 理论与文献依据

以下文献只支撑“界面附着受基底表面和材料性质影响”以及“粗糙度、孔隙/吸水、含水率不可忽略”，不直接提供本项目 `alpha_wall=0.75` 的数值：

1. Peng et al., *Experimental study of the interfacial bond strength between cementitious grout and normal concrete substrate*, Construction and Building Materials, 2021. https://doi.org/10.1016/j.conbuildmat.2020.122057
2. Courard et al., *Concrete-to-concrete bond strength: influence of the roughness of the substrate surface*, Construction and Building Materials, 2004. https://doi.org/10.1016/j.conbuildmat.2004.04.023
3. Tao et al., *Influence of substrate surface roughness and moisture content on tensile adhesion performance of 3D printable concrete*, Cement and Concrete Composites, 2022. https://doi.org/10.1016/j.cemconcomp.2021.104350
4. *Influence of capillary absorption and roughness of ceramic substrates on the adhesion of cement pastes*, Ambiente Construído, 2023. https://doi.org/10.1590/s1678-86212023000400698

这些结果共同说明：墙—砂浆界面不能只用“粗糙所以更粘”一句话概括；粗糙度、实际接触、吸水和含水状态会相互作用。因此本方案把墙面优先留料作为受约束先验，把具体强度留给敏感性分析和后续实体标定。

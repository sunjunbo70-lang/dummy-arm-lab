## 1. 先用一句话说明这轮要做什么

让机械臂先从教师处学会基本操作，再自己试验“在哪里抹、沿什么路径抹、以什么姿态和接触方式抹、什么时候继续修、什么时候结束”，用墙面的最终质量和资源消耗评价好坏，逐步找到比教师更有效的作业方法。

这轮不是让模型把教师动作背得更熟，也不是把几个固定动作播放得更久。教师是起点，物理规则是边界，任务效果是评价标准。

最终希望解决：规定区域内厚度合格、表面较平、边缘不堆高、角落不漏涂；允许工具越过规定区域一段距离收刀；能够修复自己此前造成的局部缺陷。实验先在仿真完成，实体迁移另行标定和验收。

## 2. 三个容易混淆的概念

**动作决策**：决定接下来做什么、去哪里。例如“这个角落太厚，先处理那里，不再加新材料”。

**动作生成**：决定这一笔具体怎么走。例如从哪里开始，经过哪里，工具倾多少，速度如何变化，怎样收刀。

**动作执行**：把路径变成各个关节的运动，并跟踪它。例如把工具向右移动20mm换算成六个关节的目标角度。

v0.9训练前两部分，第三部分仍由IK、轨迹约束和控制器完成。IK不是施工专家，它只是把“工具应该在哪里”换算成“关节该转到哪里”。本轮不训练电机底层驱动，也不直接输出高速关节力矩。

## 4. 总体结构：哪些模块训练，哪些不训练

```text
仿真真实世界 ──生成模拟测量──→ 观测处理/状态估计
     │                              │
     │                              ▼
     │                       可训练共享特征网络
     │                        ┌─────┴─────┐
     │                        ▼           ▼
     │                  操作决策头    条件动作参数头
     │                  选操作/位置   生成路径/姿态/接触
     │                        └─────┬─────┘
     │                              ▼
     │                       固定执行器：检查、IK、控制
     │                              │
     └────计算奖励/独立评价←────执行改变墙面
                                    │
                         训练时更新actor与critic
```

| 模块 | 输入→输出 | 本轮是否训练 | 如何训练/为何保留 |
|---|---|---|---|
| 模拟相机代理 | 真墙面→带噪声测量图 | 否 | 测量模型，不是网络；需校验其局限 |
| 观测处理/状态估计 | 扫描、历史→质量估计、余料估计等 | 首版否 | 显式可审查计算；以后可另训估计器 |
| 共享特征网络 | 地图与标量→内部特征 | 是 | BC及PPO反向更新 |
| 操作决策头 | 特征→LOAD/CONTACT/RESCAN/FINISH_REQUEST | 是 | BC学基本分类；PPO学作业顺序与停止 |
| 条件动作参数头 | 特征和所选操作→连续参数 | 是 | BC初始化，PPO探索路径及接触参数 |
| 价值网络critic | 当前观测→预期未来累计收益 | 是 | 拟合采样得到的回报，为PPO提供评价基准 |
| 轨迹解码器 | 参数→连续末端轨迹 | 否 | 数学插值，不替模型选施工方向 |
| IK与运动合法性检查 | 末端轨迹→关节目标/拒绝原因 | 否 | 保证能执行，不能被RL取消 |
| 跟踪与接触控制器 | 目标与反馈→执行 | 否 | 现有控制逻辑，单独校验其能力 |
| 材料模型 | 接触/姿态/载料→材料变化 | 否 | 环境的物理规则，不能通过训练改答案 |

Actor是“做决定的模型”；critic是训练时的“收益估计器”。critic不是教师，不给正确动作；主要估计现在的局面未来能得到多少分。本轮critic与actor使用相同允许观测，暂不引入真值特权critic，减少解释复杂度。训练完成执行动作只需actor和状态估计。

两种动作头可以共享主干，一次PPO更新同时优化。并不是必须采购/部署两个大型模型，也没有LLM文字推理环节。

## 5. 正式训练前先补可信性：不把错误仿真学进去

### 5.1 修正回放与时间轴

当前_run内部执行多个物理步后才记录一个端点，而view将端点当作固定50ms一帧；SCAN还可能替换为预设姿态。这会出现闪现和速度失真。

改动：保存模拟时间戳；按固定模拟时间采样实际qpos/qvel、姿态和必要状态；阶段事件只加标签，不擅自替换关节姿态；回放按时间播放。每个帧间隔与记录时间一致，按已知速度/加速度范围检查实际轨迹。

通俗理解：现在相当于拍摄时漏掉很多镜头，却把剩余照片当匀速电影播放。必须先补真实时间，不能只加几个“看着顺”的插值帧。

回放端可以插值用于显示，但必须标明，物理验收使用实际记录。连续不等于所有动作都必须走直线；合理曲线路径也是连续的。

### 5.2 核查运动中间的材料计算

当前部分transport用一段结束时的姿态代表整段dt。若中间倾斜、最后恢复，损失可能估错。

改动：运动过程中按固定材料积分时间步读取实际姿态并更新损失，不要求每个MuJoCo子步都计算，但需要步长收敛对照。材料不能在结束时一次性用最终姿态解释全部历史。装料前带余料、近墙旋转、离墙与扫描回程均纳入。

验证：同一路径以材料步长dt与dt/2比较损失/最终厚度，先设相对差≤5%为开发目标，接近零量时用绝对量容差；最终阈值通过误差量级确定并记录。不能把未验证的相对阈值用于所有接近零的场景。

这些修复若改变了物理结果，就建立独立物理版本，并重跑教师/BC/RL对照。旧v0.8仅作为历史参考，不把物理修复收益全归功RL。

## 6. 模型允许看什么：把真值和观测分开

### 6.1 目前不是完整相机视觉系统

D435Proxy直接对真实高度场加入偏差、倾斜、噪声和无效测量，再池化。不是从渲染深度图/点云完整重建墙面。本轮主实验继续使用这个代理以控制开发量，但命名为“带噪声高度测量”，不能宣称已完成真实D435部署。

### 6.2 新观测契约

| 信息 | Actor能否直接读取 | 处理方式 |
|---|---|---|
| 加噪声扫描、置信度 | 可以 | 所有策略共享相同测量模型 |
| 当前关节/目标执行状态 | 可以 | 明确将来来自控制器，不等于完美空间定位 |
| 已发装料指令、历史操作、剩余预算 | 可以 | 可记录的内部信息 |
| 精准墙面高度 | 不可以 | 仅奖励、物理计算和评估使用 |
| 真实quality_cost改善 | 不可以 | 用两次扫描估计改善 |
| 精准blade_volume、carry_loss | 不可以 | 估计并附不确定度，或移除 |
| fail_map、stall_count | 可以，但来源要干净 | 必须由观测/执行失败更新，不读真值 |

首版余料估计器可根据请求装料量、已知姿态/路径和估计转移量进行预算更新，输出估计和置信度；给估计加入开发集校准的偏差，不读取真实材料参数修正。它只是近似，不宣称能直接用于实物。若无法建立合理估计器，主实验先只输入装料历史和距离上次装料的工作量，不伪造精准余料。

奖励读真值是允许的：仿真可以像阅卷老师知道答案，但做决定的模型不能偷看答案。每个观测字段保存source类型（sensor/controller/history/estimate），自动检测真值字段混入。

对照三种观测：O-current（现有混合输入，仅诊断）、O-clean（无真值泄漏，主实验）、O-oracle（精准状态，性能上限诊断）。不将oracle成绩当可部署成绩。

### 6.3 局部缺陷如何看清

当前5mm格的2×4池化名义上变成10×20mm尺度，窄凸棱可能被平均掉。首版保留全局图，并加入固定位置局部/边缘高分辨率通道、坡度和置信度；明确物理尺寸，扩墙不能让S分辨率变差。

未知或低置信格必须保留unknown标识，不仅用目标厚度填充值让模型误以为已经合格。坡度由相同测量图计算，固定预处理，不用真实高度生成“干净边缘特征”。

完整虚拟深度→点云→墙面重建作为后续感知桥接，不与本轮所有算法变更一同展开。

## 7. 工作区域：允许越界，但不允许材料消失

S固定200×200mm验收区，世界位置不变。B为外围允许作业的持久缓冲区，开发比较单侧15/30/50mm；D为包含整个刀片扫掠与保护带的材料模拟域。最小边长分别230/260/300mm，但实际应由刀片角点、路径、可达性决定。

B内涂抹不按掉落处罚；保留材料，记录堆高和体积。D外材料计为流出，不能凭空清空。允许把收刀和残留凸棱移到S外，但评价缓冲堆料、材料效率和后续可处理性，防止把所有问题推出边框。

尺寸选择只用开发/验证场景，冻结后所有组一致。重建受影响可达表并记录工具/场景hash。不能事后缩评分区躲避角落失败。

## 8. 动作空间：从会选刀路，变成能描述新刀路

### 8.1 A0：现有动作空间对照

保留原模式及连续参数，仅修环境、观测、终止与学习过程。在相同改进环境中做BC→PPO，用来回答：不扩大动作自由度，RL本身是否已能提升？

### 8.2 A1：v0.9主方案

离散操作只有基础意图：LOAD装料、CONTACT接触作业、RESCAN重扫、FINISH_REQUEST请求结束。横抹、斜抹、刮平、精修不作为只能选其一的固定刀路；它们是模型最终动作的解释标签。

CONTACT连续输出19维：

| 参数 | 维数 | 通俗说明 |
|---|---:|---|
| 平面起点和终点 | 4 | 从哪里开始、在哪里结束 |
| 两个中间控制点相对直线的偏移 | 4 | 中间如何弯曲、绕过什么位置 |
| 刀片面内起止朝向 | 2 | 抹刀长边朝哪个方向 |
| 起/中/末倾角 | 3 | 接触、涂抹、收刀时立起多少 |
| 起/中/末接触设定 | 3 | 各段目标力或法向位移，按真实接口二选一 |
| 起/中/末速度 | 3 | 哪里慢、哪里快 |

LOAD另有装料量1维；其他操作不使用连续参数。未用维度不参与概率和熵损失。

路径用三次Bezier曲线，按弧长采样；可把控制点理解成“拉动曲线形状的把手”。速度剖面决定走得多快，不直接把曲线参数t当真实时间。姿态插值连续，检验中间角度与路径极值；整条路径检查可达和碰撞，不只看端点。

既有动作模板可映射成直线控制点，初始化后开放非零探索。中间点最大偏移先10mm再试30mm，最终范围根据可达测试冻结；不逐步强制拉回教师线。力/速度/姿态上限沿用现有允许范围，不为探索放宽实体限制。

本轮能创造这个参数化曲线族中的新行为，不是任意频率/任意形状的无限控制。装料轨迹初期固定，LOAD学“何时装、装多少”，不能声称装料动作本身已由RL学会。

### 8.3 统一CONTACT物理接口

先审计原DEPOSIT/REUSE/LEVEL是否通过标签直接触发不同材料规则。A1必须让转移/刮平主要由余料、接触、姿态和运动决定；不能把CONTACT表面开放、内部仍只能调用写死模板。

如果统一接口改变材料方程或操作语义，所有T/BC/A0/A1在同一新版物理上重评，单独保留旧物理对照。执行器约束只保证物理可执行，不按“像不像教师”裁动作。

## 9. 三个例子说明模型可以学出什么

例1：边缘高、旁边低。教师朝最近边界推出去；模型可能先朝低处转移材料，再以另一方向收刀。允许第一笔局部变差，只要多步总体变好。

例2：同一条凸棱。模型可能发现短斜线比长直线更有效，或者中段慢、末段减压更好。不能仅因没在示范出现就判错。

例3：接近合格的墙面。教师继续刮47次导致退化，模型应有机会学会只修两个局部缺陷后停手，或发现当前条件下无法改善而提前退出。继续工作多不是天然更优。

这些都是允许探索的可能性，不是本方案预先宣称一定会学出的结果。

## 10. 教师数据与BC：先学会基本交流，不要求成为教师复制品

教师本身是基于扫描的规则策略，每次根据状态选择参数，不完全是固定点位录像；其动作族与决策规则仍由人写定。

初始约400个示范回合：150裸墙/部分涂层、150局部缺陷、100精修残局。分层覆盖四边四角、不同余料估计、置信度及材料变化。记录实际样本数，400回合并不等于固定数量动作。

BC分类头学操作类别，连续头学对应参数；可用分类交叉熵与条件回归/似然。无效参数mask掉。教师控制点映射为相应曲线，末段没有示范的复杂行为从探索得到，不伪造已成功的标签。

示范中的失误单独标记：不能把失败动作当好动作无区别模仿，也不能删掉失败日志。有效标签用于BC，失败用于诊断与恢复场景。多个不同方向都有效时，条件/多模态表示优于将其全部平均；先检查分方向误差再决定是否增加网络复杂度。

BC准入不再要求达到教师90%成绩。检查编码、接触与学习链路，暂定受控验证可执行接触≥80%，能出现真实质量改善、无数值异常即可进入RL；若80%被证明不适合，通过开发集调整后冻结，不能用最终测试修改。

## 11. DAgger：可选短期补课，后期退出

DAgger过程是让学生操作，再让教师为学生实际遇到的状态给标签，将其加入示范。它解决“老师走过的状态和学生弄出来的状态不一样”。

本版仅可选1–2轮、每轮40回合，用于补基本执行和恢复状态。进入自主RL后不再不断用教师替换学生动作。DAgger有无作为对照，不能把它变成永远把学生拉回教师的机制。

教师不介入正式PPO采样纠正动作；若紧急执行约束拒绝动作，那是环境合法性反馈，与教师指导分开记录。

## 12. PPO强化学习：两部分一起更新，靠结果而不是老师评动作

一次采样：观测→操作头选择→参数头生成→执行器运行→新观测与奖励。将这些转移记录成batch。critic估计当前状态未来收益，PPO据此提高有利动作的概率、降低不利动作概率，并限制一次更新过大。

技术上是共享特征＋离散操作分布＋条件连续分布，联合log概率=操作log概率+该操作有效连续参数log概率。两头均得到任务奖励的学习信号。critic单独回归收益目标，也参与训练；固定执行器不会反向求导，PPO不需要通过IK计算梯度。

R1：BC→纯PPO，模仿辅助从第一轮起为0。
R2：BC→PPO＋衰减BC辅助，beta从0.1在前50轮线性降到0，以后保持0。0.1是开发起点，须检查两项梯度量级，不能让BC压住PPO。

演示batch单独计算辅助损失，不能假装是当前策略采样的on-policy数据。“on-policy”通俗说是PPO更新主要使用自己刚刚尝试的数据，而不是随意把旧教师轨迹混进去。

PPO约束相邻版本策略的更新幅度，不是永久约束学生靠近教师。连续动作方差可学习，保持非零探索；按有效维度归一化熵，离散/连续熵分别记录。熵可理解为“还愿不愿意尝试不同做法”，太低可能过早只会一种动作，太高则不停乱试。

第一版隐藏层256×256，先控制变量，不急于增大模型。先迁移A0验证PyTorch，再扩A1分支。

## 13. 奖励设计：告诉模型什么叫墙面变好

固定S上计算：合格覆盖C、RMSE、边缘RMSE、边缘超厚体积、粗糙度。当前程序已有粗糙度项，本轮改其局部表达和量级，不说此前完全没有。

J起点：
0.30×RMSE/2mm + 0.20×(1-C) + 0.20×edge_RMSE/2mm + 0.15×edge_Vplus/(edge_area×2mm) + 0.15×roughness/1mm。

J越小越好。RMSE表示整体偏离目标厚度；Vplus表示高出允许厚度的材料总量；roughness是相邻格厚度变化，并非实测表面Ra。所有归一化分母固定，记录原始指标，权重仅开发试验值。

每步r=30×(J_before-J_after)－材料损失－真实时间成本－非法动作成本。
任务终点附加−10×J_final；质量真正达标另给成功奖，初始沿用成功奖100作回报量级检查，开发阶段若明显压倒其他目标再调整并冻结。

装料成本、搬运/其他掉落/出域沿用v0.8分账基线；每笔的分母固定，不因累计供料增加而越来越便宜。规定区域外但D内材料不算消失。保护合格区的破坏比例先作诊断，增加惩罚单独消融，避免把必要材料重分布全部压掉。

不是每一步都必须得正奖励。一笔将材料推向凹坑可能暂时形成隆起，后两笔再整平，总收益更好就可以学。奖励不能只奖励抹的次数或新奇动作。

回报排序测试必须通过：多步有效修复>立刻放弃；成功结束>继续破坏；重复扫描不赚钱；堆高再刮低不能循环刷分；边界流出不能凭空清理。ΔJ是任务塑形，不声称在折扣下有最优策略不变保证。

## 14. 工作时间、停止与长期收益

保留60000基础/100000最高控制步与2000决策上限；记录实际模拟时间。装料次数60、供料量不因组别改变。至少同时报告：高层决策次数、物理控制步、模拟秒数和计算墙钟时间。

- FINISH_REQUEST允许策略随时提出；达标记录success，未达标记录give_up并结算最终质量，不用同一个FINISH含混表示。
- 平台期信号进入观测，让策略自己选择重扫、换方向或换区域；主实验不由规则接管完成修复。
- 硬停滞兜底暂设最早100决策后检查，60决策窗口，连续两个不重叠窗口没有超过噪声阈值的净改善才停。20/40/60窗口开发对照，不通过不断重置窗口无限延长。
- 探索新区域可作为停滞诊断，但不应无限豁免停止；总预算始终生效。
- 碰撞/力等执行约束维持，不为探索解除。

改善阈值通过固定墙面重复测量估计；使用窗口净变化/最佳质量而不是正改善之和，避免来回破坏修复显得“总在进步”。预算耗尽、资源耗尽、give_up、stall分别统计。

gamma起点.995，与.99对照，lambda=.95。gamma是“对更晚收益打多少折扣”，增大可让模型更重视后面的整平，但也可能增加学习噪声，不是越接近1越好。动作持续时间不同的问题先通过实际时间成本处理；若改成时长相关折扣，须同步改GAE并独立验证。

训练收集2048步就更新不表示施工结束：采样切段末的未完成环境要bootstrap（估计后面还能得多少收益），真实任务终止才按终点处理。剩余时间进入观测，避免同一墙面在不同资源条件下被当成同一状态。

## 15. 训练课程、规模与检查节奏

| 阶段 | 内容 | 暂定规模 | 放行条件 |
|---|---|---|---|
| P0 | 观测、回放、材料积分、CUDA后端验证 | 固定小数据/路径 | 无已知真值泄漏和时间记录错误，数值回归通过 |
| P1 | 理想/完整执行技能与基础示范 | 受控缺陷约120场＋400教师回合 | 物理上确有可改善动作 |
| P2 | BC及可选DAgger | DAgger最多2×40回合 | 基本执行有效，不要求教师90%成绩 |
| P3 | 自主RL短程 | 前10–20更新 | 探索非零、概率/奖励正确、无明显漏洞 |
| P4 | 正式PPO | 100→200→400更新 | 根据验证趋势决定扩展 |
| P5 | 多种子和消融 | 核心组至少3训练种子 | 方法冻结后独立测试 |

每更新2048高层决策步；100/200/400对应累计204800/409600/819200步，不相加。每批128、epochs4、lr3e-5、clip.1起步。新熵权重由短开发实验冻结，不能直接假设v0.8的零熵仍合适。

初期训练任务50%完整作业、50%精修残局；后期75%完整作业、25%难例。残局是环境合法生成的状态，初始材料进入守恒账本。固定课程切换点，例如100轮后改变比例，并记录该变化，长训练对照使用相同课程；不根据最终测试临时改变比例。

每10轮固定轻量验证；每50轮做固定开发侧完整MuJoCo验证（不是最终测试集），检查代理投机。100/200/400轮保存完整检查点。长期无改善时分析熵、拒绝、覆盖和损失，不盲目继续。暂低于教师并不触发强制停止。

长训练会降低重置频率，需记录每类实际完成回合数，防止许多步都来自极少数长局。不同worker数改变采样组成，主比较冻结worker和采样预算。

## 16. GPU计算方案：先让该上GPU的部分上GPU

CPU保留环境和IK，GPU负责BC、PPO及critic更新。单样本网络很小，推理可在worker CPU执行或集中GPU批处理，两者实测选择。不能为了显卡利用率人为把网络变大。

A0迁移时比较同一batch前向、归一化、概率、损失、梯度和一步Adam更新；再闭环短测。A1增加混合分布后另测mask、无效维度、角度、有界变换。若使用tanh变换须正确计算log概率，投影动作不能替代原采样动作概率。

计时teacher_search、env_step、material、IK、inference、update、IPC、evaluation；GPU异步计时需同步。CPU workers比较8/12/16/23，按吞吐/内存选择；性能结果与算法结果分开。

本地4080Super足以开展本规模GPU后端实验，不能预先保证提速几倍。学校服务器可分配不同训练种子/消融独立任务，暂不采用4卡同步训练这个小网络。若部署服务器，使用用户级环境，不修改系统。

本轮不同时引入MJX整体重写；否则无法区分学习方法与物理后端改变带来的收益。

## 17. 代理环境和完整MuJoCo的分工

代理/table环境便宜，用于大量探索；完整MuJoCo用于检验整条轨迹和接触执行是否兑现策略意图。两者不应被当成同一种证据。

用同状态/动作配对检查：目标与实际刀路偏差、姿态、材料转移、损失、最终质量。若代理改进而完整执行持续失败，先修可达/跟踪/材料差异，不继续烧更多代理训练步。

可增加完整执行中暴露的失败状态作为训练初始难例，或校准代理误差，但必须新建训练数据版本，避免使用最终测试场景返训后仍称独立评估。主实验先不混合不同保真环境的PPO转移，若混合需显式环境身份/域分布设计。

## 18. 实验矩阵：怎样知道改进来自哪里

先冻结可信环境与干净观测，再比较学习方法。

| 组 | 初始化/学习 | 动作 | 要回答的问题 |
|---|---|---|---|
| T | 当前教师直接执行 | 原示范 | 基础教师水平 |
| T+ | 开发阶段更强规则教师 | 更多候选 | 是否只是赢一个弱教师 |
| BC0 | 仅模仿 | A0 | 原动作空间的模仿水平 |
| RL0 | BC0→纯PPO | A0 | RL本身能否提升 |
| BC1 | 同示范映射后模仿 | A1 | 新表达下的模仿水平 |
| RL1 | BC1→纯PPO | A1 | 主实验：自由轨迹学习 |
| RL2 | BC1→衰减模仿PPO | A1 | 初期牵引是否帮助稳定 |
| Scratch | 随机初始化PPO | A1 | 示范是否提高样本效率 |

先小预算筛选，再对核心RL1/RL2及必要基线做同预算长训练。小预算Scratch失败不能证明完整随机训练永远失败。旧v0.8跨物理/观测版本仅历史结果，方法比较使用共同新环境。

消融（一次去掉一个组件）：固定新增控制点为直线；去边缘质量项；恢复旧早退；去缓冲扩展；O-clean对O-current/oracle。先做关键两三项，结果支持后扩展，不全组合训练。

公平条件：同场景初始状态、同材料供给、同工作预算、同训练步数及相同验证频率；额外示范生成和仿真成本单独报告。教师自动停止允许保留，也给“相同规则但不因原平台期提前结束”的单独版本，避免把不公平长时间优势算作算法优势。

## 19. 数据划分与防止自己给自己出题

建议开发60000–60999、验证70000–70059、最终测试80000–80059；实施前查是否已被其他实验使用，已用则换新。v0.8的50000系列只历史回归。

开发集用于试方法；验证集用于选checkpoint；最终测试只在方法冻结后评价。看完测试再调参数，下一次必须换独立测试或明确标为重复开发。

保存初始高度场、材料参数、噪声独立随机流，不能只保存seed。每组同一初始状态配对。至少含裸墙、已有粗糙层、边缘凸棱、角落堆料、邻高低区域、接近合格的精修面，并分开报告，不用残局平均掩盖整墙失败。

核心组3训练种子，报告逐种子和场景配对差值/置信区间。60个测试回合不是60次独立训练，不能混用统计层级。

## 20. 如何证明超越教师，以及如何验收绝对质量

超越教师的开发预设效果量：相同工作预算下边缘合格覆盖至少+10个百分点、RMSE至少降低15%，全域覆盖不下降、浪费不增加超过3个百分点；与T和T+分别报告。该门槛冻结后不可随结果修改。若质量与资源互有取舍，展示Pareto前沿，即哪些方案在某项更好且其他项不更差，不用一个总分遮住代价。

阶段目标（完整MuJoCo）：全域合格覆盖≥70%、边缘≥65%、RMSE≤1mm。
最终仿真目标：全域及边缘合格覆盖≥95%，RMSE≤0.5mm，P95绝对厚度误差≤1mm，并满足执行、物料和资源要求。每局分别判断，再汇总成功率。

上述目标是暂定工程目标，不是行业施工标准。超过教师、阶段改善、最终任务成功三者分别记录。若未通过，交付最佳失败结果，不改门槛宣称成功。

新行为验证：保存与教师不同且效果好的片段，在同一残局中重放；分别将曲线拉直、接触剖面改常数、替换为教师动作，比较同资源收益。这样才能知道曲线/姿态/时序是否真的有贡献。轨迹看着特别不是证据。

检查仿真漏洞：边界消料、无接触转移、姿态中途掉料遗漏、空间网格特例、频繁结束规避成本、标签触发魔法刮平。新行为在完整执行、参数扰动下仍有效才称“仿真内稳健”，实物有效须后续验证。

## 21. 每次运行要留下什么

run manifest：代码commit与dirty diff、配置hash、模型/工具/可达表hash、观测动作schema、种子、环境和后端版本。
训练记录：BC/辅助权重、策略熵、KL、critic误差、实际回合数、各任务采样量、拒绝/投影、耗时与资源。
施工记录：时间戳、真实q/qvel、动作请求/执行、模拟观测与真值分离保存、接触状态、材料账本、质量曲线、停止原因。

checkpoint含网络、优化器、归一化、RNG与进度。若没有保存所有worker环境状态，只能称参数续训，不承诺逐比特精确续跑；重启策略要明确。不同schema不静默加载旧模型。

## 23. 实施顺序、失败时回到哪里

1. 固定v0.8证据、代码与数据清单。
2. 修观测来源、时间记录、材料积分；冻结新版物理。
3. CUDA A0后端回归与吞吐测量。
4. 扩域、A1轨迹与统一CONTACT验证；确认存在有效修整行为。
5. 生成示范、BC、可选短DAgger；过基本执行门槛。
6. R1/R2短RL验证，然后100→200→400轮。
7. 核心多种子/消融、冻结选模规则、独立评估。
8. 原生MuJoCo对照展示、报告与后续实机迁移清单。

如果最简单凸棱都无法通过任何动作改善，回材料/接触模型；如果动作总被拒绝，回轨迹与可达；如果没有新探索，查方差/mask/初始化；如果只在table好，查代理差距；如果早停，查终止回报；如果后期退化，查更新与奖励。不要一律回答“再训练久一点”。

## 24. 术语速查

| 术语 | 通俗解释 | 本项目作用 |
|---|---|---|
| BC | 先照着老师学 | 初始化基本动作 |
| DAgger | 学生尝试后请老师补课 | 前期可选数据补充 |
| RL | 自己尝试，用结果改进 | 发现更有效行为 |
| PPO | 一次别改得太猛的策略优化方法 | 更新决策和动作参数 |
| Actor | 决策者 | 输出操作与轨迹参数 |
| Critic | 未来收益估计器 | 帮训练判断这次动作比预期好不好 |
| rollout | 一段尝试记录 | 收集观测、动作、奖励 |
| epoch | 同一批数据反复学习一遍 | 不等于多做一次施工 |

## 25. 本版交付边界与最终决策

本版是完整可审查规划，不是代码已经实现的声明。训练决策头、动作参数头及价值网络；不训练材料方程、IK、电机驱动或D435本体。教师只给起点，后期没有永久模仿约束。先修可信性再追求更多训练时间，以独立同预算实验判断是否超越教师。

后续优先落实第5、6节的可信性修复和第8节的真实动作自由度，再开始长RL；否则“更长、更自由”的训练可能更快找到模拟漏洞，而不是更好的施工方法。

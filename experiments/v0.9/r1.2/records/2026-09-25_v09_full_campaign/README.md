## 发现的问题与修正依据

| 问题 | 修改 | 原因与边界 |
|---|---|---|
| 连续单峰回归平均不同方向的刀路 | 8个可学习连续模式、256×256共享特征；按混合密度计算PPO概率 | 先实测分方向误差后增加多模态表示，符合方案第10节；不是8条固定模板，各头可改变19维参数 |
| 内部细节被池化而教师使用高分辨率 | 保留S内5mm高度、置信度和梯度 | 对齐可获得的传感信息；仍是带噪声高度代理，不是D435图像网络 |
| 教师知道历史余料估计但策略缺少该量 | 加入装料命令和已执行行程推算的余料 | 修复信息遗漏，不泄漏真实刀片载料；估计可能有误差 |
| 倾角可达性非单调，却向上取整查表 | 最近网格近似，完整执行仍重做IK/碰撞检查 | 不能把8度姿态当作0度姿态的保守上界；新增4度层仅留作诊断，正式矩阵冻结原表hash |
| 固定6N示教压坏墙面 | 开发扫描支持2N/4度作为修订教师起点 | 不是现实标定；T/T+与RL都在共同新物理下比较，旧v0.8只作历史 |
| 动态位置跟随滞后 | 加入速度前馈，保持原力矩上限 | 已测平均误差约8mm降到1–2mm，个别峰值仍偏大；不冒充硬件参数辨识 |
| PPO更新KL过大 | 学习率3e-6与KL 0.03停止本轮剩余更新 | 3e-5试跑曾明显破坏策略；保持所有失败检查点，记录实际完成mini-batch数 |
| 回放跳帧/重复时间 | 所有运动按真实MuJoCo时间记录；每操作清空局部帧缓冲；等待也推进物理时间 | 不能用显示插值替代未模拟的运动 |

## 完整矩阵与完成条件

campaign包含核心RL1/RL2各3个训练种子、同新环境A0对照、Scratch和直线/去边缘奖励/旧早退3项消融。100→200→400依据预先写入manifest的验证趋势扩展，不使用最终测试调参。消融固定100轮与RL1_100_reference比较；核心、RL0、Scratch按共同扩展预算运行。

选模后先报告60个验证场景，冻结检查点及源码hash，再对每组做60个独立代理场景；T/T+/BC1及6个核心策略做20个完整MuJoCo场景，达到阶段目标才扩展到60。保存教师/BC/RL同场景原生记录和最好、最差案例。最终报告必须区分：执行流程完成、超越教师、绝对质量合格。

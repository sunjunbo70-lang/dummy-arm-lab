# v0.9 边缘精修、持续修正与长时程学习完整实验方案

版本：审查稿 1.0｜2026-09-24｜状态：待审查，未实施、未训练

本文件是实验设计，不是已完成结果。依据当前工作树和 experiments/v0.8/r0/runs/v08_manual/training.json。范围为纯软件 L1；不连接或驱动实体。所有新增参数均是工程试验起点，不是材料标定值或施工行业标准。主工作区为 D:/VLA，代码基线为 D:/VLA/dummy_arm。

## 1. 最终目标、本轮问题与边界

最终目标：Dummy机械臂持抹刀，对指定墙面进行补料、搬运、铺料、局部整平和边缘精修；依据扫描与执行反馈反复修正，规定区域达到厚度和平整度要求。允许在规定区域外有限越程；材料不能凭空消失；带料姿态、轨迹连续性和可执行性必须成立。最终需走向实机验证，但仿真合格不能替代TCP、负载、接触参数和实机验收。

本轮目标：从“能扩大覆盖”推进到“能识别凸起和凹坑、选择有效修整动作、保留已经合格的区域，并在改善仍可能时继续作业”。不以占满GPU、延长动画、增大网络或训练轮数作为成功指标。

本轮保留：现有机器人运动学、已知工具配置、材料基本方程与有限供料语义。允许因技能单测暴露问题而修材料/执行器，但必须建立独立物理版本，并让全部对照重跑。暂不引入LLM/VLA，不同时更换机械结构和学习算法。新打印适配器若与lab_20260922不一致，另立几何迁移实验，不能直接宣称当前策略可上机。

## 3. 任务空间：验收区、越程区、仿真域分开

### 3.1 三层空间定义

- S：固定200×200mm验收区，40×40个5mm格，与v0.8实际评分一致。
- B：允许涂抹的持久缓冲区；比较每侧15/30/50mm。相应最小材料域边长230/260/300mm。
- D：实际材料模拟域，必须包含规划刀面扫掠包络及需要观察的保护带。若B边界不足以容纳刀片角点，D应再扩大；B与D不能混为同一个中心点约束。

世界坐标中的S位置保持不变，扩图不能因v坐标和height/2偏移而移动任务。score_mask、各边/角mask、B/D mask保存到场景清单，记录面积和坐标。

B内材料不算掉落，但记录新增材料量、最大/P95堆高和泄出边界的材料。D外材料记录为不可回收流出；保持v0.8系数1作主对照，不进一步降低来换分。新增旁区代价单独消融。禁止裁掉难以达到的评分格改善成绩。

### 3.2 可达与收刀约束

按刀面完整包络而非TCP检查墙面越程。每条候选检查起止点、途中采样、姿态旋转和关节连续性；重建受场景/工具/范围影响的可达表，文件名与哈希绑定配置。角落单独验证。拒绝时优先缩短或换方向，不能静默把边缘动作投影回中心后仍计作边缘成功。

先用四边四角分层任务选择30或50mm；选择在验证集完成。若物理上无法覆盖，报告固定全域结果与可达诊断，不事后缩S。

## 4. 物理可行性先验收：算法不能修复无效技能

建立受控初始高度场：单条边缘凸棱、角落堆料、孤立高点、凸起旁凹坑、均匀薄层、已合格平面。额外加入不同余料量、姿态、噪声与材料参数；先无噪声定位因果，再开启现有噪声。

每种技能记录接触位置、刀面姿态、目标/实际力、轨迹、材料前后分布与守恒。检查末端材料释放是否因离墙规则总在末点生成凸棱；若是模型结构导致，再好的策略也可能被迫堆料。

关键判别：理想路径是否改善 → 完整规划能否实现 → MuJoCo实际执行是否改善。分别失败对应材料模型、规划器、跟踪/接触控制，不混在一个训练失败指标中。

使用现有安全和姿态门槛；本轮不扩大实体力/关节限制。模拟峰值异常必须报告，不能通过放宽阈值绕过。小于5mm网格的纹理不能据此宣称已被准确模拟。

## 5. 控制框架：阶段管理＋可选技能＋连续参数

### 5.1 阶段有回退能力

铺料阶段：解决明显缺料；整平阶段：降低大面积厚度偏差；精修阶段：处理边缘/角落凸棱与小范围缺陷。阶段由可观测地图和置信度判断，带滞回防抖，局部严重缺料允许退回补料。不用真实隐藏高度决定策略阶段；真实状态只用于仿真奖励和独立评估。

初始实现保留v0.8基础动作，增加显式技能候选与合法性屏蔽。动作结构改变时重新生成示范，旧1116维checkpoint不能直接冒充可兼容；迁移只在明确映射及回归检查后使用。

### 5.2 技能库

| 技能 | 目的 | 参数重点 |
|---|---|---|
| PATCH_FILL | 局部缺料补给 | 负载量、短笔画、入刀倾角 |
| CROSS_RIDGE | 横穿凸棱降低高点 | 与凸棱方向夹角、长度、速度 |
| EDGE_PARALLEL | 沿边界修整连续凸起 | 边距、刀片朝向、越程端点 |
| TRANSFER_TO_VALLEY | 将过厚区材料移到邻近低处 | 高低区域连接方向、余料容量 |
| FEATHER_OUT | 越过验收边界后收刀 | 末段连续减压/离墙、姿态变化 |
| CORNER_SHORT | 角落短程或斜向修整 | 两边约束、完整刀面包络 |
| RESCAN / RECOVER | 不确定/停滞后更新状态、换策略 | 有限次数、动作失败原因 |

技能不是强制施工真理；先验证后进入教师候选。压力和速度沿用现有范围，在仿真内比较低/中档，不自动提高上限。FEATHER_OUT需要执行器支持随路径的压力或法向位移剖面，仅设置最终角度不等于减压收刀。

### 5.3 动作表示与教师

首选“技能类别＋方向类别＋连续局部参数”条件策略：离散分支交叉熵BC、连续分支条件回归；PPO联合对数概率仅包含本技能有效维度。动作mask由同一观测/合法性规则产生，采样与更新使用一致mask，保存raw action、执行action和投影信息，避免裁剪后概率不一致。

保留256×256主干作为起点，先证明表示改进而不是以网络变大解释结果。与原连续14维策略作配对对照。若改动成本过大，可先采用共享候选集、策略选择候选编号，连续残差作为第二阶段；此备选与主方案不能混报同一实验。

教师按局部预计改善选择，而非“过厚量最大就朝最近边界刮”。对候选先用缺口体积、凸棱方向、保护区和余料筛选top-K；有可克隆材料状态时做一步粗预测重排，否则明确使用启发式，并保存预测误差。教师只能使用与学生可获得的观测，禁止偷用隐藏材料参数。长度比较考虑材料需求和执行成本。

## 6. 观测、质量指标与奖励

### 6.1 观测

保留全局粗图；增加待修局部高度/厚度误差、两个方向坡度、置信度、S边界距离与角落标识、刀上余料、阶段、剩余资源、最近技能与实际改善、分技能失败热图。坡度来自同一传感模型，固定预处理，不能把噪声当凸棱。加入局部图必须明确像素物理尺寸和padding，不随扩图暗中降低S分辨率。

### 6.2 指标

S上保留合格覆盖C、RMSE、绝对误差P95、欠厚/过厚率。边缘分别报告0–15、15–30mm及30mm整体带，角落单列。新增：
- 超高体积Vplus=sum(max(h-2.5mm,0))*cell_area；报告全域和边缘。
- 超高量P95及最大值；最大值只作异常诊断，避免被单格噪声支配。
- 粗糙度：相邻格厚度差，与现有roughness定义一致；固定网格下比较，不将其称为标准表面Ra。
- 已合格格被破坏比例：本笔前合格、本笔后不合格的格数/固定S格数。
- 缓冲区材料、掉料三本账、不可达/投影率、力跟踪和质量-工作时间曲线。

### 6.3 奖励设计

当前quality_cost已经含粗糙度，本轮是加强局部质量，不是新增一个此前完全不存在的目标。

建议主实验使用固定权重质量代价：
J = 0.25*RMSE/2mm + 0.15*(1-C) + 0.15*edge_RMSE/2mm + 0.15*edge_Vplus/Vref + 0.10*roughness/1mm + 0.10*P95_error/2mm + 0.10*under_fraction。
Vref=2mm×边缘面积，所有分母固定；各归一项上限先设3作为稳健处理，同时记录未截断值。权重和截断均为试验值，先通过固定动作样本检查量级，再在开发集冻结。避免每加一项就重复惩罚同一缺陷而无控制。

r_t = k*(J_before-J_after) - lambda_damage*damage - loss_cost - time_cost - invalid_action_cost。
起点k=30、lambda_damage=2；掉料系数沿用v0.8并保留账本，时间成本保持现值作首组。终止时加入一致的最终质量评价，例如 -10*J_final；通过门槛再加成功奖励。终止质量在success、主动放弃、stall和预算结束都记录；若对所有终止施加奖励则时间上限作为有限任务终点处理，不再同时bootstrap未来价值。另一个“训练切段非任务终止”情形保留bootstrap，必须区分。

这里ΔJ是有意的任务塑形，不声称在gamma<1时保留原最优策略。禁止只给失败FINISH巨大处罚迫使无意义耗时。先审计同一残局立即停、有效修复、空转三种回报排序：有效修复最好；已无改善时有限退出优于空转。

## 7. 长时程与停止机制

保留基础60000/最大100000控制步和2000决策上限；新增记录实际仿真秒数与记账步数。控制步、技能次数、PPO采样步分别报告，不能混用。

- success：扫描估计达标后请求完成，记录真实质量是否达标及误完成率；正式仿真成功按真实状态验收。传感置信度不足先重扫。
- plateau：窗口内相对于窗口开始/最佳质量净改善不足，进入RECOVER；不用正改善之和掩盖来回振荡。
- recover：重扫、换方向、换技能或换缺陷，最多3轮，每轮最多10次高层动作（包含扫描）；试验起点。
- give_up：恢复耗尽仍无改善，明确失败退出，不再用FINISH表示成功。
- budget/resource：时间、装料次数60、有限供料等耗尽，单独标记。

对照窗口20/40，教师平台期25/50；初版40与50。改善阈值通过固定墙面重复扫描估计噪声分布来设，不直接把0.005扩大/缩小当作有物理依据。阶段切换不重置总预算和失败账本。

长训练首组沿用gamma=.99隔离新环境；另做.995对照，报告长程质量与方差。高层动作时长不等，若引入按持续时间折扣，需同时修改GAE和bootstrap并单独立项，不能只改gamma声称已解决时间尺度。

## 8. 数据、训练与GPU计算路线

### 8.1 后端迁移独立验收

当前NumPy网络迁移PyTorch/CUDA；CPU继续并行材料、教师与环境。先在v0.8冻结轨迹批次验证前向、归一化、log概率、损失、梯度和一步Adam结果，再用固定小规模闭环比较。测试容差按float64→float32差别设定并记录，不要求长随机训练逐比特相同。CPU NumPy旧后端保留。

分别计时：teacher_search、env_step、IPC、policy_inference、BC_update、PPO_update、IK/MuJoCo、eval。GPU计时需同步/事件，不能把异步提交时间当计算时间。先测workers=8/12/16/23，在相同场景上比较吞吐；GPU网络小，batch=128先保持算法公平，不承诺利用率高或固定加速倍数。

不在本轮主实验迁移整个MJX环境，避免物理后端与控制方法同时变化。GPU改造通过后再在v0.9使用；若没有实测收益，可保留CPU网络完成方法实验，计算优化单独报告。

### 8.2 训练课程与规模

P0技能单测：6类受控缺陷×20种固定场景=120场开发测试；至少覆盖四边四角。另加一组已合格平面保护测试。先理想执行、再完整MuJoCo，不需要学习。
P1精修教师与数据：初始400回合——约200局部缺陷、100已铺料粗糙面、100完整裸墙/部分涂层，具体分层数量冻结在manifest。保存扫描、技能、连续参数、执行结果、前后地图及失败。包含失败/恢复，不只收成功样本。
P2 BC/DAgger：400回合初始示范；4轮×60回合DAgger作上限，按学生访问的缺陷补标签。采样概率必须夹在[0,1]；按技能和边缘平衡标签，报告样本数而非只报回合数。验收后再PPO。
P3 PPO：每更新2048决策步，先100轮=204800，门槛通过再200轮=409600；若验证仍改善再400轮=819200。数字为累计预算，不是相加。为与v0.8匹配，minibatch128、epochs4、lr3e-5、clip.1先不改；新离散分支熵系数在短开发试验选取并冻结，不能直接继承“无熵”假设。
P4 稳定性：先1个种子作工程验证，主结果至少3个训练种子；按训练种子和场景分别报告，不能把多个测试回合当独立训练重复。

并行23路每路一次仅约89个决策的采样切段，必须在切段末对未终止环境bootstrap，保留环境状态；不能将切段当施工完成。长回合减少重置次数，需记录实际独立回合数和各任务覆盖，确保每阶段都被采到。

## 9. 对照实验与预算控制

| 编号 | 改动 | 回答的问题 |
|---|---|---|
| B0 | 冻结v0.8及旧checkpoint原环境重评 | 历史基线 |
| B1 | 仅缓冲区扩大，策略/教师规则尽量固定 | 越程空间贡献 |

| B5 | B4训练BC/DAgger＋PPO100/200/400 | 更多学习是否有收益 |

环境输入改变时旧checkpoint不能直接加载新观测，须通过明确兼容视图（保持旧S粗图）或重训旧结构；记录差别。B1-B4先教师比较，筛选后训练核心对照，避免全组合爆炸。最终另做完整方案去掉缓冲、精修技能、恢复、边缘奖励的消融；教师试验不能替代学习策略消融。

每组同时比较相同工作预算下的质量与相同质量下的工作时间；保存25/50/100/150/200次决策及结束状态、实际时间节点的指标，不强迫已成功策略继续破坏墙面。纯延长训练基线在旧方法上跑相同PPO决策预算，用于排除只因算力更多。

## 10. 数据划分与统计

v0.8的50000系列已被分析，作为历史回归，不再宣称全新测试。建议新开发60000–60999、验证70000–70059、最终测试80000–80059；完整MuJoCo初期测试可取80000–80019，正式结论建议扩至全部60。最终集在方法冻结后一次性评估，失败可以报告，不能看完再调参并仍叫盲测。

随机种子不是唯一标识：保存初始高度场、材料参数、相机噪声独立随机流、工具几何/代码/配置/可达表hash。六类场景分层，各组使用同一初始状态。

报告均值、中位数、P10质量/最差场景、配对差值和置信区间；3训练种子结果分开展示或层级汇总。不要从60个相关回合推导极高统计确定性。裸墙、部分涂层和精修残局分别报告。

## 11. 门槛与最终目标

所有数值为本项目暂定工程门槛，不是已验证可达目标或建筑验收标准。

G0软件：账本守恒在现有数值容差内；评分mask/世界坐标固定；无NaN；动作合法；原有带料/接近连续性门槛回归；无法执行的动作有明确失败记录。检查奖励归因、终止bootstrap和并行确定性。
G1技能：受控精修场景至少80%得到目标局部误差改善；目标中位改善≥20%；已合格平面被破坏面积中位≤2个百分点。联合仿真必须证明改善，不只理想材料步有效。
G2教师：匹配验证场景相对v0.8教师，边缘合格覆盖提高≥10个百分点，RMSE降低≥15%，浪费不增加超过3个百分点；若基线接近饱和则报告绝对门槛和余量，不强求不可实现的增益。受控精修与整墙分开验收。
G3学生：BC/DAgger全域和边缘合格覆盖均达到新教师的≥90%，RMSE不超过其110%，投影/拒绝无实质恶化；未通过则先修数据/动作表达，不全量长PPO。
G4本轮阶段目标（完整MuJoCo）：全域合格覆盖≥70%、边缘≥65%、RMSE≤1mm、P95绝对误差≤2mm，且同时优于配对v0.8基线；这是进入后续强化精修的目标，不是宣称施工成功。
G5最终仿真任务：至少95%的验收格在1.5–2.5mm，全域及边缘RMSE≤0.5mm、全域及边缘P95绝对误差≤1mm、边缘合格覆盖≥95%；同时保留现有姿态/执行/资源约束。每局判定再汇总成功率，不以均值达标代替所有局达标。重复扫描确认和仿真真值成功分开记录。

checkpoint按验证集硬门槛先过滤，再排序质量、浪费、工作时间；固定排序，不能最终测试后挑权重。若无模型达G4，交付最佳失败及根因，不降验收标准“宣布成功”。长期目标是在独立场景上获得高成功率，再经实机测量决定可迁移性。

## 14. 与v0.8相比为什么这样改

| 变更 | 原行为局限 | 目的与逻辑 |
|---|---|---|
| 持久缓冲区 | 15mm边缘、域外材料丢失 | 给真实越边收刀空间，防刷分 |
| 缺陷驱动技能 | LEVEL总倾向最近边界 | 根据形状和邻域需求处理凸起 |
| 离散技能＋连续参数 | 多种有效方向可能被平均 | 提高示范可学习性，保持动作语义 |
| 局部观测与保护代价 | 全局指标掩盖小凸棱 | 精修局部且不破坏合格区 |
| 有限恢复再退出 | 未耗完预算已结束 | 让额外时间用于有效修正 |
| 长PPO分阶段放行 | 单纯多训可能继续退化 | 用验证趋势决定算力投入 |
| CUDA后端独立验收 | NumPy全部CPU | 加速可加速部分，避免算法/数值混淆 |
| 教师—BC—PPO门槛 | 学生明显落后教师 | 在正确层级解决失败 |
| MuJoCo提前检验 | 表模型与执行表现差距大 | 防止代理环境刷分后末期才暴露问题 |

## 15. 执行顺序与审查结论

顺序：冻结v0.8与清单 → GPU后端独立对照/分项计时 → 区域与技能单测 → 教师消融 → 恢复与奖励回报审计 → BC/DAgger门槛 → PPO100轮 → 按验证决定200/400轮 → 冻结方法 → 独立测试与原生MuJoCo交付。

不承诺完成时长或成功率；先实测每阶段吞吐再排期。若G1失败，回材料/执行器；G2失败，回技能选择；G3失败，回观测/数据/动作表示；仅PPO退化则回奖励与优化稳定性。不可通过无限加步数跳过这些问题。

本轮建议批准的是上述分阶段实验框架。审查通过后才实施；本文件没有创建可执行的新命令，也没有启动训练。

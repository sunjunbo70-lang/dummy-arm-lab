# 抹涂手法的强化学习闭环

目标：让机械臂自己学会「一刀」的手法——回到「立起」待命位等上新料，下一刀**刀面下缘先贴住墙，
一边向上走一边逐渐放平**，把刀上的料均匀抹到墙上，少掉料、不撞墙；再把一刀一刀拼成整片。

全部是 **L1 仿真**：材料用的是降阶高度场代理模型，不是流体仿真；参数是假设值。
学出来的策略只能说明「这套奖励 + 这套环境能不能学到动作结构」，**不能直接搬到实机**。

代码：`dummy_loop/wall/material.py`（材料）、`stroke_env.py`（单刀环境）、`session.py`（多刀整片）、
`ppo.py`（纯 numpy PPO）、`rl.py`（训练闭环）。测试 `tests/test_wall_rl.py`。
记录 `experiments/2026-09-21_plaster_session_rl/`（前一版动力学的记录在 `2026-09-21_stroke_rl/`）。

## 怎么跑

```bash
python -m dummy_loop.wall rl-train --updates 100 --script-style technique --out outputs/wall/rl_tech
python -m dummy_loop.wall rl-train --updates 100 --script-style flat      --out outputs/wall/rl_flat
python -m dummy_loop.wall rl-eval  --policy outputs/wall/rl_tech/policy.npz          # 与脚本基线对比
python -m dummy_loop.wall rl-session --policy outputs/wall/rl_tech/policy.npz \
       --out outputs/wall/session                                                    # 一刀一刀抹完整片
python tools/simulation/rl_compare.py --technique outputs/wall/rl_tech \
       --flat outputs/wall/rl_flat --out outputs/wall/rl_compare                     # 三张对比图
```

每次训练单核 CPU 约 3 分钟（20.5 万步）。只依赖 numpy 与 mujoco（画图另需 matplotlib）。
没有用 torch：策略只有 7 维观测、3 维动作、两层 64，CPU 上比装训练框架还快。
以后上 ACT / Diffusion Policy 再引入 torch。

## 一个 episode = 一刀

1. **回到待命位**：刀面离墙 25 mm、俯仰 30°（上缘离墙、下缘朝墙），刀上装一份新料
   （这条带目标体积的 1.2 倍）。多刀作业时 `MortarField.reload()` 只把刀补到「一份」，不会越堆越多。
2. **抹**：策略每 0.05 s 输出一个增量，最多 60 步（3 s）。
3. **结束**：刀面走出工作区上沿，或步数用完，或接触力超过 40 N（判为撞墙，扣分）。

## 动作与观测

| 动作（3 维，每步增量） | 上限 |
| --- | --- |
| dv 沿墙竖直移动 | 8 mm/步（0.16 m/s） |
| dn 法向压入 / 退出 | 2 mm/步 |
| dpitch 刀面俯仰变化 | 0.04 rad/步，俯仰角限 ±35° |

沿墙水平移动与绕法线转角在这个任务里锁死（一刀只走一条带），逆解另外**锁住刀面 roll**，
否则解会把刀面绕刀具轴转过去，下缘就不是整条贴墙。J6 固件限位是 ±720°，这里收到 ±180°，
免得逆解给出「姿态一样但要多转几圈」的等价解。

观测 7 维，**全部是实机上拿得到的量**：由关节读数正解的刀后缘高度、指令法向位置、刀面俯仰角、
力传感器读数（墙面接触力 + 材料挤压反力）、本步位移、行程进度、已走行程比例。
真实厚度场、真实位姿这些只有仿真知道的量不进观测，只用来算奖励和评价——
否则策略会依赖实机上根本不存在的输入。

## 材料模型（代理）

墙面切成 5 mm 的格子，每格记厚度 h。刀面有俯仰角，所以它与墙的间隙沿刀宽线性变化。
决定「留下多厚」的是**后缘**（运动方向后方那条边）：前缘抬起让料流到刀下，后缘刮出最终厚度。

- 后缘经过某格：该格厚度被推到 min(h, 后缘间隙)，多的料回到刀上；不够就从刀上补（有速率上限）。
- 刀离墙超过 8 mm：什么都不发生。
- 抹到工作区以外的料算浪费；episode 结束时刀上剩的料单独记。
- 材料对刀面的反力（挤压 + 拖曳）按屈服应力 × 被刮动面积估算，加到刀面上，机械臂「感觉得到」砂浆。

**刀上兜得住多少料**（这条是「为什么要先立起再放平」在模型里的落点）：

- 没贴墙时，料靠粘附挂在刀面上，最多 `stick_free` = 8 mm 厚；
- 下缘贴墙后，料被兜在刀面与墙之间的楔形里：
  容量 = 刀长 ×(刀宽·cosθ·间隙 + ½·刀宽²·sinθ·cosθ) + 一层 `stick_contact` 粘附层；
- 超出容量的部分每步按 `spill_rate` = 0.5 挤出掉落，俯仰超过 30° 还会整体滑落。

于是「贴墙前就放平」= 楔形几乎为零 = 一贴上去就掉料；「先斜着让下缘吃住墙、边走边随料变少放平」掉得最少。
**所有系数都是假设值**。标定方法：用刮板在秤上以固定角度、固定速度刮一次，
量刮后厚度、刀前堆料量与秤的读数，反推 `capacity` / `spill_rate` / `yield_stress`。

## 奖励

| 项 | 权重 | 含义 |
| --- | --- | --- |
| 每步抹上墙的料 | +4 × 占本刀带料量的比例 | 稠密信号，没有它学不动 |
| 每步掉出去的料（区外 + 挤落） | −4 × 同上 | 掉料 |
| 力超出 2–15 N 窗口 | −0.4 × 超出的牛顿数 × dt | 压太狠 |
| 动作幅度 | −0.02 × 归一化幅度和 | 动作平滑 |
| 结束时覆盖率 | +10 × 覆盖率 | 抹到位 |
| 结束时厚度偏差 | −15 × (RMS 偏差 / 目标厚度) | 抹得匀、抹得平 |
| 结束时浪费 | −5 × 浪费比例 | 少掉料 |
| 结束时刀上剩料 | −2 × 剩料比例 | 把料用掉 |
| 撞墙（>40 N） | −5 并结束 | 安全 |

## 为什么要先做示教预热

从零探索时机械臂几乎碰不到墙，拿到的回报恒为最低分（−23），PPO 学不动。
所以流程是 **脚本示教 → 行为克隆 → 价值函数预热 → PPO 微调**：先用手写的抹涂脚本跑 20 条，
把策略均值回归到脚本动作（监督学习，几秒钟），再用 PPO 在奖励上继续优化。
这和实机上的路线是同一套：先采工人示教，再用强化学习微调。

另外三个实现细节，不做的话微调会把克隆来的手法打坏：

- **价值函数预热**：先只练 critic 一轮，否则第一次策略更新的优势估计噪声极大。
- **观测归一化冻结**：预热后不再更新归一化统计量，否则价值网络的输入分布一直漂移。
- 探索噪声要小（log_std ≈ −3，即动作上限的 5%）、学习率要小（5e-5）。噪声大了，微调反而变差。

## 对照实验：它学到的是手法，还是在背示教？

`--script-style` 提供两种示教：`technique`（工人手法：下缘先贴墙再逐渐放平）与
`flat`（不用手法：贴墙前就放平）。两次训练**动力学、奖励、超参完全一样，只有预热示教不同**。
如果强化学习只是复述示教，`flat` 这一组就该学不出东西。

### 单刀（100 次更新 × 2048 步，8 条评估 episode）

| 策略 | 回报 | 覆盖率 | 厚度 RMS 偏差 | 浪费 | 其中掉落 |
| --- | --- | --- | --- | --- | --- |
| 随机动作 | −23.06 | — | — | — | — |
| 脚本：工人手法 | −6.26 | 0.643 | 1.349 mm | 0.387 | 0.226 |
| 脚本：不用手法 | −10.52 | 0.286 | 1.135 mm | 0.496 | 0.287 |
| PPO（工人手法预热） | **+8.20** | **1.000** | **0.356 mm** | 0.205 | 0.000 |
| PPO（平刀预热） | **+8.32** | **1.000** | 0.705 mm | **0.000** | 0.000 |

两条路线都从负分学到 +8 以上，掉料降到 0，覆盖率打满。加了掉料规则之后手写脚本本身只有 0.64 覆盖，
所以这次的提升**不是「复述示教」**——示教本身是不及格的。

### 学到的是不是工人那套手法？（`raw/compare/technique.png`）

不完全是，这是目前最值得记住的一条：

- **共同点（奖励真正逼出来的）**：两条策略都把**后缘间隙锁在目标厚度 2 mm** 上并一路保持，
  同时让俯仰随刀上剩料一起下降——料快用完时才彻底放平。这正是「抹得匀」的物理条件。
- **不同点**：手法预热的策略保持大角度（28° → 12°）缓慢放平，接近工人手法；
  平刀预热的策略只保留 2°~4° 的小俯仰，靠精确的间隙控制拿到同样的回报。
- 所以：**当前奖励唯一确定的是「后缘间隙 = 目标厚度」，不是「俯仰角必须从 30° 放平」**。
  想让它必然学出工人的大角度手法，要么把带料/掉料物理做得更真（标定过的 `capacity`），
  要么直接对姿态加约束或加奖励项。现在的写法两种解都接受。

## 多刀整片（`dummy_loop/wall/session.py`）

一刀只能抹一条带（刀长 × 一个行程）。`run_session()` 把区域切成若干条带，
**逐条试逆解筛掉够不到的**（所以「机械臂能活动的范围」是算出来的，不是拍脑袋定的），
然后一条一条抹：回待命位 → 上料 → 一刀 → 抬刀，共用同一块高度场，最后按整片算指标。
策略只学「一刀」，回位、横移、上料是固定脚本——它们不影响抹涂质量，没必要学。

3 条带 × 7 cm、196 cm² 的结果：

| 驱动方式 | 覆盖率 | 平均厚度 | 厚度 RMS 偏差 | 平整度 σ | 浪费 |
| --- | --- | --- | --- | --- | --- |
| 脚本：工人手法 | 0.898 | 1.94 mm | 0.879 mm | 0.876 mm | 0.386 |
| PPO（工人手法预热） | 0.980 | 2.09 mm | **0.371 mm** | **0.361 mm** | 0.256 |
| PPO（平刀预热） | 0.980 | 2.50 mm | 0.819 mm | 0.646 mm | **0.144** |

单刀学到的策略**直接迁移到整片**（没有为整片再训练），指标就比脚本好。厚度图上还剩两个缺陷：
**起刀处堆料过厚**（刀刚贴墙那几步把料挤在起点）与**条带之间有台阶**（没有搭接策略）。

### 换条带的过渡轨迹：一个没解决的限制

`SessionConfig.simulate_transit` 默认 **False**（每刀直接从该条带的待命位开始）。
打开它会复现这个问题：锁住刀面 roll 之后，相邻条带的自然逆解常常落在**不同的腕部支解**上，
横移过去要把 J4/J6 各转一百多度，而 **J6 是直驱、力矩只有 0.07 N·m 量级**，中途刀面还会扫到墙。
已经加了「先退到 8 cm 停放距离再换支解 + 逐点检查逆解」的处理，仍不够稳。
**换条带需要专门规划过渡轨迹**（或允许刀面绕法线转一定角度），列为待办。
这只影响带与带之间的移动，不影响单刀手法的结论。

## 局限（实机验证前必须记住）

- 材料模型是代理模型，系数是假设值；**仿真里学到的最优手法不等于真实砂浆下的最优手法**。
- 奖励不唯一确定手法（见上），「学到了技巧」要限定为「学到了奖励定义的那部分技巧」。
- 带与带之间的移动没有仿真；起刀堆料与条带接缝还没处理。
- 关节伺服刚度、摩擦、延迟都还没实测，力的数值不可当真。
- 策略输入里没有相机，真实施工中「看着哪里薄就补哪里」这一步还没有——接上深度相机后才能补。
- J6 减速器的减速比仍是**假设的 30**（照片里确有减速器，型号未确认）。

## 下一步（按收益排序）

1. **标定材料模型**：刮板 + 电子秤，测「角度 / 速度 / 压入量 → 留下厚度、掉料量、拖曳力」，
   把 `capacity` / `spill_rate` / `yield_stress` 换成实测值。这一步不做，后面的数字都是假设。
2. **起刀与接缝**：把起刀段的堆料和条带搭接写进奖励（或加一道收光行程）。
3. **换条带的过渡轨迹规划**，打开 `simulate_transit`。
4. **接相机**：把深度图/厚度估计加进观测，才谈得上「看到哪里薄补哪里」。
5. **域随机化 + 实机示教**：`--random-scale` 已经在了，实机采到工人示教后换掉手写脚本。

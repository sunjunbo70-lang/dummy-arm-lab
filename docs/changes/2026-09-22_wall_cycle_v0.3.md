# 整片连续强化学习 v0.2 → v0.3：改了什么、为什么改、不要改回去的理由

日期：2026-09-22　证据等级：全部 L1（仿真），未连接机械臂
上一版：提交 `9b5716f`（`dummy_loop/wall_cycle/`，实验 `experiments/2026-09-22_wall_cycle_rl/`）
本版：实验 `experiments/2026-09-22_wall_cycle_v03/`

> **读这份文档的目的**：以后有人看到 v0.3 的某个改动觉得「多余」「太复杂」「原来那样更简单」，
> 先在这里查它为什么存在、改回去会重新出现什么问题。每一条都写了：
> **v0.2 的问题 → 证据（能复现的数字）→ 改成了什么 → 为什么这样改 → 改回去会怎样 → 守护它的测试**。

---

## 0. 一页结论

v0.2 的方向是对的：从「一刀怎么抹」扩展到「整面墙怎么安排」，引入了 D435 观测、余料复用、
完整作业循环和守恒的材料账本。但复核发现它有三类根本问题：

1. **仿真与机械臂脱节**：训练里没有机械臂，动作「从 A 抹到 B」不检查够不够得到、撞不撞墙；
   作业区 28×7 cm 是沿用的旧设定，不是按可达范围算的；3D 回放是事后补逆解画的折线图。
2. **材料物理有错，而且没有手法**：压得越重抹得越厚（方向反了）、刀上的料会从一头穿到另一头、
   超力判定永远不会触发；刀面没有俯仰角，所以用户要的「立起 → 下缘先贴墙 → 放平」根本不存在。
3. **结果评价不可比**：行为克隆和 PPO 用不同的测试种子比较；展示的回放是挑出来的成功种子。

v0.3 的改动都是针对这三类问题。**v0.2 的记录和模型原样保留，并且可以逐位复现**（见 C12）。

### C1 作业区：从真实可达范围按用户规则计算

- **v0.2 的问题**：作业区 28×7 cm（196 cm²），来自更早的单刀实验「3 条带 × 7 cm」，**从未按机械臂可达范围算过**。
  它又扁又小：只有 7 cm 高，一刀竖向行程就走完了。
- **用户规则**：在机械臂操作范围内找最大的圆 → 取内接正方形 → 边长取 80% 留安全冗余。
- **改成了什么**：`tools/simulation/v2_trowel_reach.py` 在 25–38 cm 多个墙距上，用 1 cm 网格逐点求逆解，
  得到墙面上真正可作业的点集；用距离变换找最大内切圆；内接正方形边长 ×0.8，再向下取整到 5 mm 材料网格。
  结果写入 `dummy_loop/wall_cycle/work_area.json`，由 `area.load_work_area()` 读入配置。

  | 墙距 | 最大圆半径 | 作业正方形（×0.8） |
  | --- | --- | --- |
  | 28 cm | 13.5 cm | 15.3 cm |
  | 30 cm | 14.5 cm | 16.4 cm |
  | **33 cm** | **16.5 cm** | **18.7 → 18.5 cm（取整）** |
  | 35 cm | 16.3 cm | 18.4 cm |
  | 38 cm | 14.5 cm | 16.4 cm |

  选定：墙距 33 cm，正方形中心 u = −1 cm、离底座底面高 19 cm，**18.5 × 18.5 cm = 342 cm²**
  （v0.2 的 1.75 倍，且是正方形）。
- **为什么用「宽松版」**：每个点只要求刀面正对墙能贴上、并能退到离墙 2.5 cm。**没有**要求每个点都能「立起 30°」，
  因为 v0.3 要让强化学习自己决定角度；倾斜的刀在边缘够不够得到，由执行器逐刀检查（C7/C8）。
  严格版（要求 30° 也够得到）在同一墙距下的结果见实验记录 `raw/reach/`，面积明显更小。
- **80% 的含义**：按「边长 × 0.8」处理（面积为 64%）。若指面积 80%，边长改为 ×0.894，改 `SAFETY` 一个数。
- **改回 28×7 会怎样**：任务区与机械臂能力无关，学出来的策略在别的区域没有意义；作业区也远小于用户要求的范围。
- **测试**：`test_wall_cycle_v03.WorkArea`。

### C2 可达分析工具的三个修正（本版开发中发现，写下来防止再犯）

1. **漏了桌面**：第一版扫描时「可达区域」一直延伸到桌面高度 z=0，抹刀和连杆会穿过桌面。
   现在所有部件（含刀片）离桌面 ≥ 5 mm，除刀片外的部件离墙 ≥ 5 mm。
2. **臂的几何体不参与碰撞**：场景里臂的几何体 `contype=0`（只做显示），MuJoCo 的碰撞检测不会报它们，
   第一版的「碰墙检查」实际上什么也没检查。改为 `mj_geomDistance` 直接算几何距离。刀颈与刀片几何体重叠，算作抹刀本身豁免。
3. **倾斜时刀缘插进墙里**：工具点是刀面中心。刀面倾斜 θ 时，中心必须离墙 半宽·sinθ，否则后缘在墙里
   （30° 时 6.9 mm）。第一版的严格扫描与执行器都犯了这个错；现在由 `ArmExecutor.contact_n()` 统一处理。

另外要求离墙 2.5 cm 的待命位也可解：能贴上墙却退不出来的点不能作业（首轮联合仿真在正方形底边暴露了这个问题）。

### C3 材料模型重写：基于物理，不写入答案（方案 B）

- **v0.2 的问题**（均已复现）：

  | 问题 | 证据 |
  | --- | --- |
  | 压力越大抹得越厚（真实情况相反） | 同一刀：2 N → 2.03 mm，8 N → 2.33 mm，15 N → 2.38 mm |
  | 刀上的料会从刀的一端「穿越」到另一端 | 平滑用了 `np.roll`（周期边界）：只在一端放料，刀离墙一次后另一端出现 1.3e-2 |
  | 超力判定永远不会触发 | `peak = F + 1800 × 刮下体积(m³)`，第二项量级 1e-3 N；20 局中最大 8.0 N，阈值 40 N |
  | 没有刀面俯仰角 | `stroke()` 没有这个参数；「立起 → 下缘贴墙 → 放平」在模型里不存在 |
  | 抹上的厚度由固定比例和固定阈值决定 | 补到 2.5 mm（`acceptable_high`）、超过 3.5 mm 刮掉，与刀的位置无关 |

- **用户的判断**：旧模型学不到倾斜手法，是因为材料被当成「严格粘在工具上」，没有模拟它会流动。
  比起写一条强制倾斜的规则，应该把材料模拟对，让模型自己学出不掉料的角度。
- **改成了什么**：`dummy_loop/wall_cycle/mortar.py`。砂浆是屈服应力材料（宾汉型）：剪应力低于屈服应力时像固体，超过才流动。
  参数只有物理量：密度 1900 kg/m³、屈服应力 250 Pa、塑性黏度 2 Pa·s
  （Banfill 2003 表 1：砂浆约 400 Pa、1–3 Pa·s；抹灰砂浆更软，故取 250 并做敏感性分析）、
  刀离墙时层在墙与刀之间的分配比例 0.5（假设值，待测）、层内输运系数 0.5（Couette 平均，假设值）。
  机制：
  1. **挤压力平衡决定间隙**：压紧力由刀下被挤压的砂浆支撑，压力从自由边为 0 起以 2τ_y/g 的斜率上升；
     解「支撑力 = 指令力」得到后缘间隙。**力越大层越薄**（方向改对了）。支撑不住时钢刀碰墙（间隙 0）。
  2. **刮平**：前缘遇到的墙面料并入刀下料柱；墙面相对刀向后滑，按 Couette 平均速度把料柱带向后缘；
     后缘离开的格子留下 min(料柱, 间隙)。补低、削高是同一个机制。
  3. **挤出**：料柱超过间隙的部分被挤出，按两侧边缘间隙³ 的比例分配（薄膜流量 ∝ 间隙³）。
     平放的刀一半挤到刀后面（留下「刀痕」），倾斜的刀几乎全挤到前面，形成被后续推平的料埂。
  4. **刀面上的重力排流**：刀面倾角决定沿面重力分量，层厚超过 τ_y/(ρ g_t) 的部分向下流；
     流到贴墙（封住）的边就被兜住，流到自由边就掉落；刀面朝下悬垂时，重量超过屈服应力的层整体剥落。
  5. **墙面坍落**：竖直墙上超过 τ_y/(ρg)（约 13 mm）的层会塌落。
  体积严格守恒（测试要求误差 < 1e-15 m³）。
- **结果：倾斜手法是「算出来的」而不是「写进去的」**（单刀扫参，`tools/simulation/mortar_sweep.py`，
  记录 `experiments/2026-09-22_wall_cycle_v03/raw/mortar_sweep.json`；一刀竖向行程、随机 24 mL 载料、4 个种子，
  评分 = 带内平均层厚 − 2 × 浪费率）：

  | 屈服应力 | 单刀最佳俯仰 | 浪费率：平刀 → 30° |
  | --- | --- | --- |
  | 100 Pa（很稀） | 5° | 50% → 40% |
  | 250 Pa（基准） | 15° | 25% → 12.5% |
  | 500 Pa | 20° | 14% → 3% |
  | 1000 Pa | 30° | 8.7% → 0.7% |

  浪费随倾角单调下降，最佳角度随材料变硬而增大。单刀评分下最佳力总是取在下界（0.5 N）：一刀抹不到 2 mm，
  层越厚分越高，这是单刀评分的性质，不代表整片作业的最优力，整片由强化学习自己权衡。
  倾角的趋势与工人经验一致（「刀越平留料越多，越陡刮得越干净」），也说明**材料参数必须实测**：
  同一套物理，不同的砂浆学出来的角度不同。
- **为什么不做完整 CFD/MPM**：强化学习要数万次决策，每刀必须毫秒级。MPM（如 Genesis、Taichi）更适合在 GPU 服务器上
  跑少量典型刀次，用来**验证**这个降阶模型（列为后续工作）。
- **改回 v0.2 会怎样**：力的方向反了，学到的「压重一点就厚一点」在实机上正好相反；没有俯仰角，手法学不到；超力保护形同虚设。
- **测试**：`test_wall_cycle_v03.MortarPhysics`（力→间隙单调、挤出方向、排流、守恒、无环绕、无角度参数、倾斜在硬砂浆下更省料）。

### C4 否决的草案：「楔形兜料容量」规则

本版开发中曾写过一条规则：刀上能兜住的料 = 刀与墙之间楔形体积，随俯仰角增大。
它能让模型「学会」倾斜，但那是因为我们**先写下了倾斜能兜住料**——答案被写进了仿真器，实验就失去了意义。
按用户意见删除，未发布。**不要重新加入任何以角度为自变量的经验规则**；角度只能通过几何（间隙、重力方向）起作用。
`test_no_parameter_prescribes_a_pitch` 守护这一点。

### C5 动作空间：13 维，力范围 0.5–15 N

- 新增 `pitch_start`、`pitch_end`（0–35°），刀面俯仰在一刀内线性变化。「立起 → 放平」是其中一种，平刀也是一种，由策略选。
- v0.3 力范围改为 0.5–15 N（v0.2 为 2–15 N，原字段 `force_window` 保持不变，v0.2 策略按原范围解码）。
  **原因**：基准屈服应力下，倾斜刀面只靠窄条砂浆支撑，几牛顿就会压到钢刀碰墙；2 N 下界让大部分倾斜刀次只能压穿砂浆。
  （单刀扫参里最优力仍落在下界，原因见 C3 末尾：那是单刀评分偏好厚层，不是整片作业的结论。）
- **改回 2 N 下界会怎样**：倾斜手法在很多情况下只能压穿砂浆，学习结果被动作边界而不是物理决定。

### C6 LEVEL 与 REUSE 物理上相同

v0.2 里 LEVEL 只削不补、DEPOSIT/REUSE 只补不削，是两套手写规则。v0.3 的刮平机制（C3-2）本身就同时补低削高，
区别只在「这一刀前是否上料」。模式名保留（观测里有「上次模式」，也便于阅读动作日志），但不要再为 LEVEL 写单独的物理。

### C7 每一刀在真实机械臂上规划并联合仿真

- **v0.2 的问题**：训练中没有机械臂。回放时才对事后结果补逆解，失败帧标黄；最早一版有 11 个失败帧。
- **改成了什么**：`dummy_loop/wall_cycle/arm.py`
  - `plan()`：在 Dummy V2 + 刚性抹刀场景上，从墙面往外倒推规划：接触位（刀缘不入墙）→ 立起的待命位 → 放平的后退位；
    再沿同一条贝塞尔曲线求工作路径，最后抬刀、后退。任何一点无逆解、关节超限、除刀片外离墙 < 5 mm、
    或接触阶段相邻姿态关节跳变 > 20°，整刀拒绝（策略受罚、不接触墙面）。
  - `execute()`：**MuJoCo 动力学与材料模型联合仿真**：每个采样点 MuJoCo 推进机械臂（位置伺服、V2 力矩上限、重力补偿），
    材料反力加在刀片上；读回**实际**刀面位置、俯仰和后缘间隙驱动材料模型；导纳力环调节离墙量使实测法向力跟踪指令。
- **开发中发现并修正的问题**（都有测试守护）：
  1. 后退位求解允许重新播种，落到另一支腕部解（J6 转了约 180°），J6 只有 2.1 N·m 转不回来，整刀以翻转的刀面执行，
     刀面中心恒偏 14 mm。现在后退、待命、接触各姿态之间关节跳变不得超过 20°。
  2. 每个采样点的逆解未达 2 mm 容差时保留旧指令，机械臂因此恒定落后约 3 个采样点。现在总是采用改进后的解。
  3. 工具点（tcp）在刀片长度方向离刀面中心 7 mm；材料模型用刀面中心，逆解目标已换算。
  4. 趋近动作用固定 0.25 s，机械臂还没到位就开始抹；现在按 60°/s 关节速度加稳定时间计时。
- **仍是近似的地方**：伺服增益 kp=35 为示例值未辨识（跟踪误差约 6–8 mm 即来自于此）；刀与刀之间的移动（去扫描位、装料位）
  不做动力学仿真；材料只以合力作用回刀面（不是完全的双向流固耦合）。

### C8 训练用可达表，评估用完整联合仿真

- **原因**：完整规划一刀约 0.1 s，PPO 需要数万次决策。`reach_table.py` 在作业区 × 刀角 8 档 × 俯仰 4 档 × 运动方向 2 档上
  预先跑完整规划器，训练时查表（起点、中点、终点都可行才接受），材料按名义路径计算。
- **代价与透明度**：查表是近似的。训练结束后，教师与最终模型都在**完整规划 + 联合仿真**下重测，
  报告两种环境下的差异（`test_cosim`）。
- **不要做的事**：不要只报告查表环境下的数字。

### C9 观测池化适用于任意网格

v0.2 的 `coarse_map` 在网格不是 2×4 的倍数时直接返回未池化的图，观测维度随之静默改变。
作业区改成 37×37 格后会触发。现在先按边缘值补齐再池化。测试：`test_coarse_map_pools_any_wall_shape`。

### C10 评估方法

| v0.2 | 问题 | v0.3 |
| --- | --- | --- |
| BC 用 30 局（种子 11000+），PPO 用 100 局（种子 20000+） | 不同测试集，比较不成立 | 教师、BC、PPO 都在同一组 100 局（种子 20000–20099）上测 |
| 用测试集结果选模型 | 选择偏差 | 独立验证集（种子 30000+）选模型，测试集只用于报告 |
| 回放展示种子 2219（成功，覆盖 0.995） | 默认种子 2209 失败；40 个种子中成功 15 个 | 回放默认用选中的模型和固定种子，报告同时给出多种子统计 |

v0.2 中 PPO 实际比 DAgger 差（回报 36.2 → 24.5，成功率 0.40 → 0.30），STATUS 表只写了 PPO 的覆盖率。

### C13 探索噪声

v0.2 所有维度 log_std = −3（动作范围的 5%）。从平刀教师出发时，俯仰只在 ±0.9° 内试探，
PPO 永远发现不了倾斜是否更好。v0.3 对力和俯仰三个维度用 −1.5（约 ±4°），其余维度保持 −3，以免打散教师学到的「在哪里抹」。

### C14 预热教师

- **问题一：v0.2 教师在新物理下很差。** 平刀教师浪费 84%、覆盖 0.25，行为克隆学到的起点太低。
- **改法（对两种风格一视同仁）**：接触力、每次装料量、行程离边缘的余量这三项与俯仰无关，
  在 2×2×2 网格上按「平刀教师与手法教师的平均回报」选定：1 N、12 mL、离边 2 cm
  （`env.teacher_force_N / teacher_load_ml / teacher_edge_margin_m`）。只用一种风格来选会偏向那种风格。
- **问题二：「手法」教师从来没有倾斜过。** 它在行程起点（正方形底部）立起 25°，而这个墙距下 J5 已接近固件限位 −100°，
  底部 4–8 cm 内向上抹时 20° 以上的「下缘先贴墙」都不可执行；回退逻辑随即退成平刀，两种教师实际上一模一样。
  可达表里的证据：向上抹、刀长水平时，20° 在 v = 0/2/4 cm 行的可行比例为 0.0/0.2/0.4，30° 在 10 cm 以下几乎为 0；
  反过来「上缘先贴、向下抹」20° 几乎处处可行。
- **改法**：「手法」教师在每个起点按 25° → 20° → 10° → 0° 的顺序，取机械臂能执行的最大立起角，再放平。
  平刀教师不变（3°）。
- **结果**（同一批 10 局、查表环境）：手法教师浪费 17.7%、RMSE 1.90 mm、回报 −24.4；
  平刀教师浪费 33.7%、RMSE 2.32 mm、回报 −30.6。**只差俯仰的两个教师，倾斜的更好**——这是物理算出来的。
- **不要做的事**：不要只按平刀教师调这三项参数，也不要把「手法」教师改回固定 25°（会在这台机械臂上悄悄退化成平刀）。

### C15 刀前料埂随刀推进（开发中修正）

第一版把刀前挤出的料直接放到墙上，同一个采样点结束时就做墙面坍落判定，刀还没推到就判它「挂不住掉了」。
平刀教师 395 mL 供料中有 245 mL 因此「坍落」。真实情况是料埂靠在移动的刀面上被推着走。
现在料埂作为刀的一部分随刀前进，下一采样点从前缘回到刀下；抬刀时才落到墙上（此时坍落、推出边界才真正生效）。
平刀教师浪费由 84% 降到 67%（设置调整前）。

### C16 执行层动作投影（安全层）

- **问题**：v0.3 第一次训练中，行为克隆出的策略约一半的刀次落在不可执行的格子（主要是底部的倾斜刀，见 C14），
  被整刀拒绝；「连续 5 个无改进循环」规则随之在约 8 个循环后结束回合，覆盖率停在 0.2 左右，
  PPO 学到的主要是「如何少被拒绝」，而不是怎么抹。
- **改法**：执行层先尝试最接近的可执行变体——倾角降到 2/3、1/3、0，行程向正方形中心收 0/20/40%——
  找到就执行并扣 0.5 分（记 `projected_strokes`），都不行才拒绝（记 `unreachable_strokes`，扣 2 分）。
- **为什么不算作弊**：机械臂约束一点没放松，**不可执行的刀永远不会被执行**；投影只是把「提议」变成「最近的合法动作」，
  这是机器人安全层的常规做法，实机上也应该有同样的一层。策略仍会因为被修正而扣分，有动力提出可执行的动作。
- **不要做的事**：不要把投影去掉改回直接拒绝（会重现上面的早停）；也不要把投影扩展到放松关节限位或碰撞检查。
- **测试**：`test_wall_cycle_v03.ActionProjection`。

## 2. 已知局限（不要把 L1 结果当成实机结论）

- 屈服应力、黏度、分离比例、输运系数都是文献值或假设值；**最佳角度随屈服应力变化**，必须做刮板 + 电子秤实验标定。
- 伺服增益未辨识；刀与刀之间的移动没有动力学仿真；材料对机械臂只以合力作用。
- 可达表是近似，已在联合仿真中复核并报告差异。
- 关节限位是 V2 固件候选值，M3 实测后作业区要重算（重跑 `v2_trowel_reach.py`）。
- 降阶模型没有与 MPM 等高保真仿真交叉验证（后续在 GPU 服务器上做）。

## 4. 结果（详表见 `experiments/2026-09-22_wall_cycle_v03/README.md`）

1. **倾斜有利是物理算出来的**：单刀扫参中浪费随倾角单调下降，最佳俯仰随屈服应力增大（100 Pa 5°，250 Pa 15°，1000 Pa 30°）。
2. **整片作业里也成立**：只差俯仰的两个教师，立起（机械臂允许的 10°）比平刀（3°）浪费 16.5% 对 32.5%、
   RMSE 1.95 对 2.31 mm（测试集 100 局）；联合仿真下 10.7% 对 43.4%。
3. **强化学习方向对、幅度小**：从平刀起步，PPO 把实际执行的俯仰从 3.8°（模仿）推到 5.0°，浪费 36.5% → 30.6%；
   但 61k 步内没有学出完整手法，两组 PPO 的回报都没超过各自的教师（主要损失在行为克隆后的安全层修正）。
4. **整片任务远未解决**：覆盖率 0.22–0.27，无一局满足完成判定。
5. **机械臂限制手法**：J5 接近 −100° 限位，底部 4–8 cm 内向上抹时 20° 以上的下缘先贴墙不可执行。

## 5. 下一步（按收益排序）

1. 修斜向刀次的网格混叠（刀面足迹超采样），它直接抬高 RMSE 并干扰学习。
2. 刮板 + 电子秤标定屈服应力、分离比例；标定后重跑单刀扫参与训练（最佳角度会随之变）。
3. M3 实测 J5 等限位后重算作业区与可达表。
4. 加大训练量、改进模仿（更多 DAgger、让策略学会先提可行动作），再看 PPO 能否超过教师。
5. 在 GPU 服务器上用 MPM（Genesis / Taichi）跑少量典型刀次，交叉验证降阶砂浆模型。

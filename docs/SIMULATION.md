# 墙面抹涂仿真链路

目标：在不接实机的情况下，把「场景 → 控制 → 任务 → 示教数据 → 误差与补偿」整条链路跑通并量化，
为实机实验提前做出设计决定。全部是 L1 证据：**仿真结论只能指导设计和下一步测量，不能预测实机表现。**

代码在 `dummy_loop/wall/`，数据格式在 `dummy_loop/episode.py`，约定在 `docs/ACTION_SPACE.md`，
测试在 `tests/test_wall_sim.py`，证据在 `experiments/2026-09-20_wall_sim_chain/`（参考模型）与
`experiments/2026-09-20_v2_model/`（**V2 模型，当前版本**）。

> **2026-09-20 切换到 V2 模型。** 场景现在建在 `models/dummy_v2.xml` 上（固件 DH 运动学、V2 限位与传动参数、
> J6 裸轴末端，见 `docs/hardware/DUMMY_V2.md`）。世界系改为固件基座系（+X 朝前），墙在 +X 方向。
> 下面第 1–5 节是用参考模型得到的原始记录，数字保留不改；V2 重跑的结果在本文末「V2 重跑」一节。

## 怎么跑

```bash
python -m dummy_loop.wall demo --viewer                        # Windows 上打开 MuJoCo 窗口看一遍抹涂
python -m dummy_loop.wall demo --random-scale 1 --probe --servo # 随机误差 + 两种补偿，打印指标
python -m dummy_loop.wall collect --episodes 50 --random-scale 1 --probe --servo --out outputs/wall/episodes
python -m dummy_loop.wall replay outputs/wall/episodes/ep_0000.npz   # 回放，检验录下的数据能复现这条 episode
python -m dummy_loop.wall study --out outputs/wall/study        # 敏感性分析（约 30 秒）
python -m dummy_loop.wall layout --out outputs/wall/layout.json # 工位布局搜索（约 45 秒）
python -m dummy_loop.wall scene --out outputs/wall/scene.xml    # 导出场景 MJCF，可直接用 MuJoCo 打开
python -m dummy_loop.wall render --out outputs/wall/camera      # 固定相机 RGB + 深度
```

只依赖 `requirements/core.txt`（numpy、mujoco）。画图脚本 `tools/simulation/plot_wall_study.py` 另需 matplotlib。

## 场景（`scene.py`）

在 `models/dummy_reference.xml` 之上用 MjSpec 程序化组装，**不修改原文件**：

- 转接件（刚性）→ 弹簧滑轨（被动柔顺，行程 30 mm，k = 400 N/m，预紧 2 N）→ 抹刀（80 × 50 mm 占位刀面）
- 刀面中心在 J6 轴线上：沿墙拖曳力对 J6 不产生扭矩（见 `experiments/2026-09-20_static_torque`）
- 只有刀面与墙面之间计算接触，机械臂连杆仍然不参与碰撞
- 固定相机 `d435`（位置占位），传感器：压缩量、刀面受力
- 所有尺寸都是参数（`SceneConfig`），每一项是假设、占位还是测量值写在 `provenance()` 里，随 episode 保存

## 设计发现

### 1. 腕部奇异：刀面正对墙面并沿墙水平移动，是这台臂最难的动作

锁住 J1、J4、J6 时，刀面正对墙面的姿态只存在于一条竖线上（x ≈ 1.8 cm，连杆的横向偏置）。
任何水平移动都要转 J1，J1 一转刀面就偏航，而手腕纠正偏航只能靠 J4 滚转去「借」J5 的方向。
手腕伸直（J5 ≈ 0）时 J4 与 J6 共线，是经典的腕部奇异：一点点偏航需要 J4、J6 大幅反向转动。
早先按「墙距 25 cm、刀面垂直于 J6 轴」试算时，J4、J6 被逼到 ±80–90°，每步关节跳变 5–20°。

应对：
- 控制器把刀面 roll 放成弱约束，多出一个冗余自由度用来远离奇异（`controller.py`）
- 关节代价加权：J1、J4、J6 更贵，优先用肩、肘、腕俯仰
- **工位布局用搜索决定，而不是按可达面积决定**（下一节）

### 2. 「够得到」不等于「好干活」

`experiments/2026-09-20_wall_workspace` 按可达面积算，墙放在距 J1 轴 20–30 cm 面积最大。
但那些点大多是蜷缩、贴近奇异的姿态。`layout.py` 改用「整片工作区上的最差条件数」评分，
在 96 个候选（刀面倾角 × 墙距 × 工作高度）里只有 20 个能覆盖 12 × 10 cm 的工作区，最优的是：

| 刀面倾角 | 墙距（距 J1 轴） | 工作区中心高度 | 最小奇异值 | 离限位 | 最大腕扭 |
| --- | --- | --- | --- | --- | --- |
| 0°（刀面垂直于 J6 轴） | 40 cm | 20 cm | 0.023 m/rad | 21° | 30° |

这也是结构最简单的转接件（同轴）。默认场景采用它。**这些都基于假设的 ±90° 关节范围，M3 实测限位后必须重跑。**

### 3. 示教要按「自己发出的指令」规划，而不是按控制器的当前状态

有指令延迟时，控制器目标滞后若干周期。示教若以它为反馈，会在每个路点附近过冲、回拉、再过冲，
形成延迟引起的极限环（仿真里一段路要走几万步）。示教改为累计自己发出的动作作为规划基准后，
1–3 周期延迟下都正常完成。**实机上的任何策略同理：它永远知道自己发过什么，不要拿滞后的状态闭环位置。**

### 4. 误差与补偿

误差模型（`errors.py`）的每一项都对应实机上一个可命名、可测量的来源：

| 仿真误差项 | 实机来源 | 在哪一步测 / 消除 |
| --- | --- | --- |
| 逐轴零位误差 | 固件零点 ≠ 规范零点 | M3 逐轴标定 |
| 指令延迟 | 串口排队、固件缓存 | M2 时效契约 |
| 关节读数噪声 | 编码器分辨率与噪声 | M2 录包统计 |
| 墙面偏移、偏转、前后倾 | 墙板摆放 | 探触标定（每次开工） |
| 弹簧刚度比例 | 弹簧公差、导轨摩擦 | 台架上用秤压一次 |
| 摩擦系数比例 | 材料 | 抹涂压力实测（秤） |
| 关节伺服刚度比例 | 闭环步进的等效刚度 | 实机加载测下垂 |

两种补偿，都只用实机可得的量：
- **探触（probe）**：开工前在工作区三个角沿法线慢速逼近，压缩量超过 1 mm 记为接触，拟合真实墙面平面并更新
  控制器的墙面系。探触在机器自己的运动学里完成，所以同时吸收了局部的零位误差。
- **压缩量闭环（servo）**：抹涂时按压缩量读数修正压入深度，累计修正有上限（15 mm）。

结果（30 组随机误差，量级按标定前的合理范围，见 `Perturbation.sample`）：

| 补偿 | 平均覆盖率 | 最差 | 最大接触力（最差） |
| --- | --- | --- | --- |
| 无 | 0.907 | 0.271 | 16.5 N（超出 15 N 窗口） |
| 仅压缩量闭环 | 0.916 | 0.723 | 13.5 N |
| 仅探触 | 0.966 | 0.852 | 12.7 N |
| 探触 + 闭环 | 0.966 | 0.852 | 11.8 N |

- 最差的那一组（0.271 → 0.981）是墙比预想远 15 mm 且前倾 4°：不探触时刀面几乎碰不到墙。
- 覆盖率的收益几乎全部来自探触；压缩量闭环主要作用是把压力拉回设计值、压低峰值。
- 单因素里最敏感的是关节伺服偏软（kp × 0.5：0.73）和摩擦偏大（× 1.7：0.81），探触后恢复到 0.94–0.96。
  这两项的真实数值目前都不知道，所以它们首先是「最该先测什么」，而不是预测。

**对硬件的直接含义**：探触只需要「碰到了」这一个开关量。在转接件的弹簧滑轨上装一个微动开关
（行程 1 mm 左右触发）就能拿到大部分收益；连续的压缩量读数（直线电位器或霍尔）是第二步。

### 5. 一个被推翻的结论

修正示教的延迟问题之前，仿真显示「无误差时压缩量闭环把覆盖率从 0.958 提到 1.000」，当时解释为
补偿了伺服下垂。修正后这一提升消失：它主要来自闭环与示教互相拉扯导致行程变慢、停留时间变长。
这里保留记录，说明上面的数字都以修正后的版本为准。

## 数据链路

`python -m dummy_loop.wall collect` 录下的每条 episode 是一个 `.npz`，格式见 `dummy_loop/episode.py` 与
`docs/ACTION_SPACE.md`。`replay` 用录下的动作在同一场景、同一误差、同一种子下重放，四条样本全部逐位复现指标，
说明录下的内容足以还原 episode（含探触时的墙面系更新事件）。M2 只读录包与 M7 采集器应写同一种文件。

## 没有建模的东西

齿隙与回差、连杆长度误差、减速器柔性、温漂、墙面不平整、材料流动与堆积（MuJoCo 是刚体引擎）、
D435 深度噪声与空洞、机械臂连杆与墙的碰撞（只算刀面-墙面接触）。这些不在上面的结论覆盖范围内。

## V2 重跑（2026-09-20，当前版本）

场景换成 `models/dummy_v2.xml` 后，布局、敏感性分析、静力矩全部重跑。关节范围改用 **V2 固件限位**
（J1 ±170°、J2 −75…90°、J3 0…180°、J4 ±180°、J5 −100…120°、J6 ±720°，固件角），不再用假设的 ±90°。
记录与原始数据在 `experiments/2026-09-20_v2_model/`。

**布局**：96 个候选里 27 个能覆盖 12 × 10 cm 工作区（参考模型是 20 个）。前四名：

| 刀面倾角 | 墙距（距 J1 轴） | 工作区中心高度 | 最小奇异值 | 离限位 | 最大腕扭 |
| --- | --- | --- | --- | --- | --- |
| 0° | 40 cm | **15 cm** | 0.035 | 19.1° | 20.0° |
| −30° | 40 cm | 30 cm | 0.034 | 15.9° | 19.4° |
| 0° | 35 cm | 20 cm | 0.026 | 20.7° | 31.6° |
| 0° | 40 cm | 20 cm（原默认） | 0.022 | 33.9° | 31.1° |

默认场景改为墙距 40 cm、工作区中心高 15 cm、刀面垂直于 J6 轴（同轴转接件，结构仍最简单）。
原来的 20 cm 仍可行，离限位更远但更靠近腕部奇异。V2 各连杆共面，刀面正对墙面的竖线就在 u = 0（参考模型是 1.8 cm）。

**误差与补偿**（30 组随机误差，同一随机种子与量级）：

| 补偿 | 平均覆盖率 | 最差 | 最大接触力（最差一组） |
| --- | --- | --- | --- |
| 无 | 0.934 | 0.350 | 14.6 N |
| 仅压缩量闭环 | 0.944 | 0.760 | 12.5 N |
| 仅探触 | 0.980 | 0.917 | 15.8 N |
| 探触 + 闭环 | 0.980 | 0.925 | 13.3 N |

结论与参考模型一致：**覆盖率收益主要来自开工前探触**；压缩量闭环主要压低接触力峰值。
单因素里仍是伺服偏软（kp × 0.5：0.85 → 探触后 0.95–0.96）与摩擦偏大（× 1.7：0.90 → 0.97–0.98）最敏感；
J2 零位误差 2° 使覆盖率降到 0.91，探触后 0.95。四条录制样本回放全部逐位复现。

**静力矩**（`tools/simulation/static_joint_torque.py`，V2 估计质量，工具长 20 cm）与 V2 额定值对比：

- 压 10 N、拖曳系数 1.0 时 J2 需约 5 N·m，超过 MINI11-50 额定 3.5 N·m（未超启停峰值 8.3）；
  压 20 N 时 J2 约 11 N·m，超峰值。**抹涂压力先按 5–10 N、摩擦偏小的工况设计。**
- J5（MINI8-50）在 10 N / 系数 1.0 时约 3.0 N·m，接近其启停峰值 3.3 N·m，是第二个瓶颈。
- **J6 直驱**：电机保持转矩只有 0.07 N·m 量级，拖曳 5 N 时刀面接触中心偏离 J6 轴 14 mm 就会超过。
  转接件必须同轴；偏心安装的工具应固定在 J6 电机座外壳上。
- 这些质量是估计值，J2 的数字对大臂与小臂质量最敏感，称重后重算。

## 末端改为 J6 减速器 + 尖头抹刀（2026-09-20，当前默认）

实际末端：去掉原「J6 减速器 + 夹爪电机 + 夹爪」里的夹爪电机和夹爪，减速器输出法兰上装 3D 打印抹刀座，
卡住日式尖头抹刀的木柄（刀面 120 × 27.5 mm，木柄与刀面平行、垂直于 J6 轴）。整个末端刚性，没有伸缩。
前面各节里的「弹簧滑轨 + 压缩量」是早期设计选择，现在保留为 `--tool spring` 仅作对比；默认场景、演示、录制、
敏感性分析都改用刚性抹刀。尺寸按照片估计，记录在 `experiments/2026-09-20_rigid_tool/`。

30 组随机误差：

| 补偿 | 平均覆盖率 | 最差 | 最大接触力（最差一组） |
| --- | --- | --- | --- |
| 无 | 0.378 | 0.000 | 141 N |
| 仅力闭环 | 0.867 | 0.408 | 133 N |
| 仅探触 | 0.658 | 0.179 | 93 N |
| 探触 + 力闭环 | 0.893 | 0.654 | 47 N |

与弹簧方案的主要差别：**刚性方案下「能不能抹」取决于有没有接触力测量**。探触和压力闭环都改用法兰与抹刀座之间的
力传感器（`tool_force_N`，连续 2 次超过 2 N 判定接触）。没有它，平均覆盖率不到 0.4，并会出现远超关节能力的撞墙力。
20 Hz 的位置增量式力闭环只有约 73% 的时间把压力保持在 2–15 N 内，实机上要低速接近、增益从小往大调、设硬性力上限。
刚性刀面对关节零位误差敏感（刀面一边先贴墙），M3 标定 J2、J3、J5 零位，或在抹刀座里留一点被动自适应（小角度橡胶垫）。

# ADR-0001：以 Dummy V2 实机资料作为硬件权威源

日期：2026-07-27
状态：Accepted

## 背景

项目同时包含多个 Dummy 分支、复刻版本、机械模型、PCB 资料和固件。
不同来源在接线、PCB 版本、减速比、关节方向和零位等方面可能冲突。

## 决策

采用“上游归档 + 实机 profile 覆盖”的方式：

- 外部仓库和历史资料保留原貌。
- V3.0.7 指南作为当前实机明确事实的最高优先级文档。
- 实机测量和标定结果在完成复核后可补充指南未覆盖的参数。
- 项目代码只读取 `configs/` 中的实机 profile，不直接依赖某个上游仓库的默认参数。
- 任何会改变实机运动学或电气行为的冲突必须显式记录，不允许静默选择。

## 结果

- 可以持续吸收上游更新而不破坏实机配置。
- 仿真、算法和真机共享同一套显式参数。
- 需要额外维护参数来源、版本和验证状态。

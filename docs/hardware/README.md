# 硬件基线资料

本目录三份文档抽取自 2026-07-27 建立的 `dummy_v2/` 工程，内容保持原貌未改写。
原工程在 2026-09-18 工作区重构中退为纯归档（`_archive/dummy_v2/`），
其文档部分因与实机直接相关而并入本基线。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| USB_COMMAND_PROTOCOL.md | 文本命令协议：控制、查询、动作命令与驱动实现要求 | M2 只读链路、M3 标定的协议依据 |
| DUMMY_V2_ACTUAL_BASELINE.md | 实际硬件基线：PCB 版本、接线、供电、电机 ID | 参数裁决时的事实来源 |
| ADR-0001-硬件权威顺序.md | 资料冲突时的裁决顺序 | 遇到互相矛盾的旧资料时按此判断 |

与本目录并列的 `../HARDWARE.md` 是本工程自己的实机使用边界，记录已验证的设备身份、
预设姿态和当前调试包络。两者的关系是：本目录说明协议和硬件事实，`HARDWARE.md`
说明这台具体机器上验证到什么程度。

注意 ADR-0001 的核心结论：目录名含「Dummy V2」不等于该资料与真机一致。
方向、零位、减速比、软限位等未在 V3.0.7 手册中明确的参数，必须经源码交叉检查
和低风险真机标定后才能写入正式配置。这与 `core.py::load_profile` 的门禁逻辑一致。

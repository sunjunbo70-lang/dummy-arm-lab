# Dummy V2 仿真模型（`models/dummy_v2.xml`）

2026-09-20 起，墙面抹涂仿真、实机同步上位机画面、`六轴同时往复仿真.cmd` 都改用这份 V2 模型。
它对应用户实机：Dummy V2，末端是 **J6 电机裸轴**（Φ5 D 形轴，没有法兰）。

证据等级：**L1（资料 + CAD）**。按 `DUMMY_V2_ACTUAL_BASELINE.md` 的事实源顺序，V2 资料包排在第 4 位，
所以下面所有参数都是**候选值**：可以用来做仿真和设计，不能写进 `configs/` 的已标定字段，
M3 在实机上逐项测量后才能升级。

## 2. 坐标与零位（最重要的约定）

- 世界系 = 固件基座系：原点在 J1 轴线上，**+X 朝前，+Z 向上**，+Y 向左。底座底面在 z = −7.5 mm。
- **模型关节零位 = 固件 HOME (0, 0, 90, 0, 0, 0)**，即 L 形：大臂竖直、小臂水平朝前、J6 轴朝 +X。
- **模型关节角 = deg2rad(固件角 − HOME)，正方向与固件相同**。上位机画面直接这样换算，不需要符号表。
- 模型的正运动学与固件 SolveFK 逐位一致：`tests/test_dummy_v2_model.py` 在 V2 限位内随机 300 组姿态核对，
  末端位置与姿态误差 < 1e-9。站点 `fw_end` 就是固件的末端点（腕心沿 J6 轴外伸 L_WT = 75.5 mm）。

| 参数 | V2（用于模型） | 原版源码（资料包内 `dummy_robot.cpp`，仅对照） |
| --- | --- | --- |
| L_BASE / D_BASE | 126.5 / 35 mm | 109 / 35 mm |
| L_ARM | 146 mm | 146 mm |
| D_ELBOW / L_FOREARM | 52 / 117 mm | 52 / 115 mm |
| L_WRIST | 75.5 mm | 72 mm |

CAD 对齐：装配体画在收纳姿态 FOLD (0, −75, 180, 0, 0, 0)。用四个减速器中心定位关节轴：
J2 → J3 轴距在 CAD 里量得 146.0 mm，与 L_ARM 相同；J4 轴、J6 电机中心也落在固件 DH 预测的位置上。
CAD 的腕部相对 J1 竖直平面有 0.7 mm 横向偏差（固件 DH 假设各轴共面），对外观无影响，已记在参数表。

## 3. 传动与执行器

| 关节 | 电机（CAD） | 传动 | 减速器 | 固件减速比 | 固件限位（度） | 模型执行器上限 |
| --- | --- | --- | --- | --- | --- | --- |
| J1 | 42-34 | 直连 | MINI11-50 | 50 | −170 … 170 | 8.3 N·m |
| J2 | 42-40 | GT2 20T:20T 皮带 | MINI11-50 | 50 | −75 … 90 | 8.3 N·m |
| J3 | 42-34 | GT2 20T:20T 皮带 | MINI11-50 | 50 | 0 … 180 | 8.3 N·m |
| J4 | 35-28 | 直连 | MINI11-50 | 50 | −180 … 180 | 6.0 N·m |
| J5 | 35-20 | GT2 20T:20T 皮带 | MINI8-50（改轴输入） | 50 | −100 … 120 | 3.3 N·m |
| J6 | 35-20 | **直驱，无减速器** | — | **5（冲突，见下）** | −720 … 720 | 0.07 N·m |

- 执行器上限 = min(减速器启停允许峰值, 电机保持转矩 × 减速比)。J4 由电机先到限（0.12 × 50 = 6.0）。
  额定（可持续）值 J1–J4 为 3.5 N·m、J5 为 1.8 N·m，写在 `models/dummy_v2_params.json` 的 `drivetrain`。
  未计减速器效率与闭环驱动的实际电流设置，真实可用值更低。
- armature（反射惯量）= 转子惯量 × 减速比²：J2 0.0135、J1/J3 0.0085、J4 0.0028、J5 0.0015 kg·m²。
- 伺服 kp = 35、kv = 4、阻尼 0.3 仍是示例值，没有辨识。

## 4. 质量（估计）

结构件按 3D 打印等效密度 0.85 g/cm³；标准件按材质；电机与减速器按资料质量整体分摊到它们的 CAD 实体。
若你的实机结构件是 CNC 铝件（资料包里两套文件都有），用 `--structure aluminium` 重新生成。

| 连杆 | 质量 kg | 主要内容 |
| --- | --- | --- |
| base_link | 0.87 | 底座、J1 电机与减速器 |
| link1 | 0.33 | J1 输出座、J2 减速器（部分） |
| link2（大臂） | 1.23 | J2 电机、J3 电机与减速器 |
| link3（肘） | 0.63 | J4 电机与减速器 |
| link4（小臂） | 0.47 | J5 电机、MINI8 减速器 |
| link5（J6 电机座） | 0.20 | J6 电机 |
| link6（裸轴） | 0.003 | Φ5 钢轴 |
| **合计** | **3.73**（运动部分 2.86） | |

电机 / 减速器跨两个连杆的，是按零件离哪个子装配最近划分的，连杆间的质量分配是近似的。
**上秤称整机与小臂后替换**，这是最便宜、收益最大的一次测量。

## 5. 裸轴末端

- CAD 量得：J6 输出轴 **Φ5.0 mm（D 形）**，轴端距腕心 **73.4 mm**；电机前端面 56.4 mm；
  J6 电机座外壳前端 60.4 mm，所以**露出外壳约 13 mm**，露出电机端面约 17 mm。
- 固件 L_WT = 75.5 mm，比 CAD 轴端远 2.1 mm：固件末端点在轴端外侧一点。上位机里的末端坐标指的是这个点。
- 模型里：`shaft_tip` 站点 = 轴端面，`fw_end` 站点 = 固件末端点。墙面场景的转接件从 `shaft_tip` 起算。
- 转接件设计含义：J6 直驱，静态可承受扭矩只有电机保持转矩（35-20 典型 0.07 N·m 量级）。
  **刀面接触中心必须落在 J6 轴线上**；偏心 20 mm、拖曳 5 N 就需要 0.1 N·m，可能把 J6 拖转（见实验记录的静力矩结果）。
  若必须偏心，把工具固定在 J6 电机座外壳上而不是轴上。

## 6. 资料冲突（M3 必须实测）

1. **J6 减速比**：V2 固件截图写 5，装配体里是直驱。若固件按 5 换算而实际直驱，J6 实际转角可能与指令相差 5 倍。
   M3 从 J6 开始，用 ≤ 5° 的小角度、低速测一次实际转角。
2. **电机长度**：BOM 写 3 个 42-40、2 个 35-28、1 个 35-20；装配体里是 J1/J3 42-34、J2 42-40、J4 35-28、J5/J6 35-20。
   以实机铭牌为准（质量差约 0.1 kg 量级）。
3. 资料包里的固件源码仍是原版参数（减速比 30、DH 109/115/72），与 V2 截图不同。
   2026-09-16 预设复核中 J2 到达 −74.9997°，与 V2 下限 −75° 相符，支持「实机刷的是 V2 参数」，但不是证明。

## 7. 重新生成

```bash
pip install gmsh cadquery-ocp      # 仅建模需要
python tools/modeling/build_dummy_v2.py --step "<资料包>/4.Model/Dummy V2 版本 视频款/Dummy-B v2装配体.step"
python -m unittest tests.test_dummy_v2_model
```

参数（DH、限位、电机、减速器）只在 `dummy_loop/v2.py` 一处定义；改了之后重新生成模型，测试会核对模型与参数一致。

## 8. 没有变的东西

- `models/dummy_reference.xml`（auk 参考模型）与 BC 冒烟闭环保持原样，历史冻结数字仍可复现。
- `SimRobot()` 不带参数时仍加载参考模型；V2 用 `SimRobot(V2_MODEL)`。
- 2026-09-20 之前用参考模型录的墙面 episode 不能在当前代码上重放（关节坐标约定不同），
  `replay` 会给出明确报错；它们的记录与数字保留在原实验目录，不改写。

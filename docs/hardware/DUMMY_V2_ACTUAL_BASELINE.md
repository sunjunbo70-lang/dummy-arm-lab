状态：生效

## 适用对象

本项目控制、仿真和实验所对应的真实硬件是“Dummy V2 任同学实际版本”。
其他开源仓库、旧版模型、PCB、固件参数和说明只作为参考，不自动代表实机。

## 事实源优先级

遇到减速比、关节方向、零位、限位、板卡、接线、引脚或协议冲突时，按以下顺序处理：

1. `dummy使用指南_V3.0.7.pdf` 中的明确说明。
2. 在当前实机上完成并记录的测量、标定和验收结果。
3. 与当前 Dummy V2 板卡和固件版本确认匹配的源码、模型和电路资料。
4. `upstream/dummy-v2-ren-archive/` 中未确认版本的历史资料。
5. `upstream/dummy-classmates-version/`、`upstream/dummy-v1-auk/` 及其他外部仓库。

低优先级资料不能静默覆盖高优先级事实。发生冲突时必须建立 ADR 或问题记录。

## 已确认硬件事实

- 实物 PCB 版本为 V1.0.1；旧资料可能仍展示 V1.0.0。
- REF 到 J1 使用反向线。
- J1 到 J6 均使用反向线。
- 推荐使用 12 V 稳压电源，额定电流至少 6 A。
- 24 V 可兼容但不推荐用于当前调试和初期验证。
- 电机驱动板 P1 为电源/CAN 输入，P2 为电源/CAN 输出，P3 为烧录口。
- REF 板 P1 为电源/CAN，P2 为 ST-LINK/UART1 烧录口，P3 为灯环接口。
- 2025-08-09 之后的板卡可能将 6P 烧录口改为 5P；引脚定义基本不变，但必须按实物确认。
- J1-J6 的拨码 ID 从 1 开始；拨码方向可能随批次改变，不能只按开关外观推断。
- Type-C 正反面连接到不同芯片；电脑不识别时应断电确认后翻转插头重试。
- 电机必须先逐个完成编码器校准，再进行多轴联机。
- 上电前机械臂必须折叠并对准实际硬件刻度，因为主控会把上电位置作为初始参考。

## 尚未确认，禁止猜测

以下参数不能仅凭其他仓库或旧截图写入实机配置：

- 六个关节的精确零位偏置。
- 六个关节的实际正方向。
- 当前固件对应的减速比。
- 实机软限位和机械硬限位。
- 连杆质量、质心和惯量。
- 摩擦、阻尼和控制周期。
- 当前主控及六块驱动板的固件提交或固件哈希。

这些参数必须通过实机辨识、固件读取或受控实验确认，并记录在
`docs/experiments/` 和 `configs/robot/` 中。

## 使用约束

- 不直接修改 `upstream/` 中的历史源码作为长期实现。
- 项目代码通过 `configs/` 中的 Dummy V2 profile 读取实际硬件参数。
- 仿真和真机必须使用同一组关节命名、单位、方向和零位约定。
- 在完成限位、限速、超时、通信失联和物理急停验证前，不允许模型直接驱动真机。

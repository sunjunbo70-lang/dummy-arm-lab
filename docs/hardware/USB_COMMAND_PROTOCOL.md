# Dummy V2 USB 文本命令协议

本文档整理自实际硬件指南 V3.0.7 和匹配固件源码。正式驱动必须通过测试确认响应格式，
不能仅根据本文档假设真机行为。

## 传输层

- 介质：Type-C / USB 串口。
- DummyStudio 发布包配置：USB Vendor ID `0x1209`，波特率 `115200`。
- 指南要求发送工具使用 `<CR><LF>` 结尾。
- 命令大小写和符号必须准确。

## 控制命令

| 命令 | 作用 | 风险说明 |
| --- | --- | --- |
| `!START` | 使能所有电机 | 发送前必须确认校准、零位和关节方向 |
| `!STOP` | 请求停止当前运动 | 软件停止，不等同于物理急停 |
| `!HOME` | 移动到展开/7 字位置 | 方向错误会导致撞机 |
| `!CALIBRATION` | 执行校准相关操作 | 只允许在明确的标定流程中使用 |
| `!RESET` | 回到起始收缩位置 | 必须先确认当前姿态和路径安全 |
| `!DISABLE` | 关闭使能 | 仍需验证断使能后的机械保持行为 |

## 查询和参数命令

- `#GETJPOS`：读取六轴关节位置。
- `#GETLPOS`：读取末端位置和姿态。
- `#SET_DCE_KP`、`#SET_DCE_KI`、`#SET_DCE_KD`：设置电机控制参数。
- `#REBOOT`：重启指定节点。
- `#CMDMODE`：设置命令模式。

PID、重启和命令模式属于维护接口，算法运行时不应随意调用。

## 动作命令

关节空间：

```text
&j1,j2,j3,j4,j5,j6
```

示例：

```text
&0,0,134,35,66,0
```

末端位姿：

```text
@x,y,z,a,b,c
```

示例：

```text
@175,44,160,-135,-13.54,-14.6
```

固件源码还支持部分命令携带速度字段。正式 SDK 必须在协议测试完成后再开放该参数。

## 驱动实现要求

1. 连接后先执行只读探测，不自动使能。
2. 校验返回字段数量、数值范围和超时。
3. 所有角度和位姿在发送前经过单位、零位、方向和限位转换。
4. 串口断开、响应超时或数据异常时停止继续下发动作。
5. 记录发送时间、原始命令、原始响应和解析结果。
6. 禁止把发送目标当作编码器实测反馈。

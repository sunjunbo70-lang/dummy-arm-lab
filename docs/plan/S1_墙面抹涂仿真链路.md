# S1 墙面抹涂仿真链路

状态：第一版完成（2026-09-20）
会话类型：软件会话
目标证据级：L1
前置：无（与 M2/M3 并行；结论需在 M3 之后用实测参数重跑）

## 为什么现在做

实验室停电期间唯一能推进的是仿真侧。把任务定义、动作空间、录制格式、误差模型先在仿真里定下来，
等实机可用时唯一的新变量就是硬件本身。

## 已完成

- 场景（MjSpec，不改原模型）、末端动作空间与逆解、覆盖任务、脚本示教
- 通用 episode 格式（与 M2 时效契约一致），录制—回放逐位复现
- 误差模型与两种补偿（探触、压缩量闭环），30 组随机误差的量化
- 工位布局搜索

证据：`experiments/2026-09-20_wall_sim_chain/`；说明：`docs/SIMULATION.md`、`docs/ACTION_SPACE.md`。

## 待做（按依赖顺序）

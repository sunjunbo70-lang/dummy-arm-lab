## 本阶段的三条硬指标

M4 收尾时全部达成才算解锁完成：

1. **正式 API 通路打开。** `python -m dummy_loop jog --joint N --delta-deg 1 --enable`
   在标定后的 profile 下跑通，首目标与实体姿态一致。
2. **单一设备真值。** GUI 与 CLI 共用同一份 profile，`configs/README.md` 中
   「二者尚未合并成统一设备 profile」可以删除。
3. **时间戳可信的录包。** 录出 10 条以上只读 episode，每帧带来源、主机接收时刻
   和帧序号；人为断连时日志标 stale，而不是继续显示旧值。

## 任务卡格式

每张卡包含：状态、会话类型、目标证据级、前置、我做什么、你做什么、验收、
证据落点、回滚。执行中随时更新状态，完成后在 `docs/STATUS.md` 增行。
